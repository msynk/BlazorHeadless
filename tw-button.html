Button

A polymorphic, accessible button primitive with loading and disabled states.

Implementation: CSS Tailwind

Basic Button

Renders a native <button> with no styling. All visuals come from Tailwind utility classes.

Clicked 0 times
<BhButton OnClick="HandleBasicClick"
          class="inline-flex items-center gap-2 rounded-lg border border-zinc-200 bg-white px-4 py-2 text-sm font-medium text-zinc-900 hover:bg-zinc-100">
    Click me
</BhButton>
/* All styling lives in Tailwind utilities — no custom CSS file needed. */

class="inline-flex items-center gap-2 rounded-lg
       border border-zinc-200 bg-white px-4 py-2
       text-sm font-medium text-zinc-900 cursor-pointer transition-colors
       hover:bg-zinc-100 hover:border-zinc-300 active:bg-zinc-200
       focus-visible:outline-2 focus-visible:outline-offset-2 focus-visible:outline-blue-600"

Disabled State

Sets the native disabled attribute and emits data-disabled. The data-disabled: variant styles the disabled look. 

<BhButton Disabled="true"
          class="... data-disabled:opacity-50 data-disabled:cursor-not-allowed data-disabled:pointer-events-none">
    Can't click me
</BhButton>
/* The custom data-disabled: variant maps to [data-disabled] selector. */

class="...
       data-disabled:opacity-50
       data-disabled:cursor-not-allowed
       data-disabled:pointer-events-none"

Loading State with Context

Uses RenderFragment<BhButtonContext> to drive a spinner from the button's own state. 

<BhButton Loading="@isLoading" OnClick="Save"
          class="... data-loading:opacity-70 data-loading:cursor-wait" Context="btn">
    @if (btn.Loading)
    {
        <span class="inline-block h-4 w-4 animate-spin rounded-full border-2 border-current border-r-transparent"></span>
        <span>Saving…</span>
    }
    else
    {
        <span>Save Changes</span>
    }
</BhButton>
/* The custom data-loading: variant maps to [data-loading] selector. */

class="...
       data-loading:opacity-70
       data-loading:cursor-wait"

/* Spinner uses Tailwind's animate-spin + a transparent right border. */
class="inline-block h-4 w-4 animate-spin rounded-full
       border-2 border-current border-r-transparent"

Polymorphic Rendering

Set As="a" to render as an anchor while keeping all button semantics. Non-native elements receive role="button", tabindex="0", and Enter/Space handling.

I'm actually an <a> tag I'm a <span> with role="button" 
<BhButton As="a" href="https://github.com" target="_blank"
          class="inline-flex items-center rounded-lg px-4 py-2 text-sm font-medium text-blue-600 underline hover:text-blue-700 hover:bg-blue-50">
    I'm actually an <a> tag
</BhButton>

<BhButton As="span" OnClick="HandleClick" class="...">
    I'm a <span> with role="button"
</BhButton>
/* Link variant — transparent border, blue text, blue-50 hover. */

class="inline-flex items-center gap-2 rounded-lg border border-transparent
       bg-transparent px-4 py-2 text-sm font-medium text-blue-600
       underline underline-offset-2 transition-colors
       hover:bg-blue-50 hover:text-blue-700"

Toggle Button

Combine BhButton with your own state to build a toggle. Pass aria-pressed via standard HTML attributes — they merge automatically. 

<BhButton OnClick="Toggle"
          class="@(isPressed
            ? "... bg-blue-600 border-blue-600 text-white"
            : "... bg-white border-zinc-200 text-zinc-900 hover:bg-zinc-100")"
          aria-pressed="@isPressed.ToString().ToLowerInvariant()">
    @(isPressed ? "ON" : "OFF")
</BhButton>
/* Toggle button — driven entirely by your own bool state. */

class="@(isPressed
        ? "... bg-blue-600 border-blue-600 text-white hover:bg-blue-700"
        : "... bg-white border-zinc-200 text-zinc-900 hover:bg-zinc-100")"

Styled via Data Attributes

Style entirely via the registered data-disabled: and data-loading: variants — no component API for visuals. 

<BhButton OnClick="HandleClick"
          class="... bg-zinc-900 text-white data-disabled:opacity-40 data-loading:opacity-70">
    Styled via [data-*]
</BhButton>

<BhButton Disabled="true" class="...">Disabled via [data-disabled]</BhButton>
<BhButton Loading="true"  class="...">Loading via [data-loading]</BhButton>
/* Style entirely via custom data-* variants registered in input.css. */

class="bg-zinc-900 text-white
       data-disabled:opacity-40 data-disabled:cursor-not-allowed
       data-loading:opacity-70  data-loading:cursor-wait"
