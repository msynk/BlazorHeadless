# BlazorHeadless documentation site

Static documentation for [BlazorHeadless](https://github.com/msynk/BlazorHeadless), generated from the live sample pages in `src/BlazorHeadless.Samples/`.

## Stack

Plain HTML and CSS, with [Prism.js](https://prismjs.com/) loaded from a CDN for code syntax highlighting. No frameworks, no build step at runtime — the site is fully static and ready to serve from GitHub Pages.

## Generating the site

The HTML pages are generated by `build.mjs`, which reads the razor sample pages and writes the documentation files in this folder. Re-run it whenever sample pages change.

```bash
node docs/build.mjs
```

Requires Node.js 18+. No npm dependencies.

## Serving locally

Any static file server will do. For example:

```bash
npx serve docs
```

Or open `docs/index.html` directly in a browser.

## Deploying to GitHub Pages

In the repository settings, enable GitHub Pages with **source = `docs/` folder on `main`**. The `.nojekyll` file disables Jekyll processing so files starting with `_` are served as-is.

## Layout

```
docs/
├── index.html               # Overview
├── getting-started.html     # Getting started
├── components/
│   ├── accordion.html
│   ├── button.html
│   └── ...                  # one page per component
├── assets/
│   ├── main.css
│   └── main.js
├── build.mjs                # Generator
├── .nojekyll
└── README.md                # This file
```
