Fieldset

Group a set of form controls together with a fully accessible but much easier-to-style version of the native fieldset and legend elements.

Basic example

Use BhFieldset and BhLegend to group a set of form controls together with a title. The fieldset uses the native <fieldset> element while the legend renders as a <div> (since native <legend> is notoriously hard to style).

Example

Razor

<BhFieldset class="fieldset">
    <div class="fieldset-header">
        <BhLegend class="fieldset-legend">Shipping details</BhLegend>
        <p class="fieldset-hint">Where should we deliver your order?</p>
    </div>

    <BhField class="field">
        <BhLabel class="field-label">Street address</BhLabel>
        <BhInput name="address" class="field-input" />
    </BhField>

    <BhField class="field">
        <BhLabel class="field-label">Country</BhLabel>
        <BhSelect name="country" class="field-input field-select">
            <option>Canada</option>
            <option>Mexico</option>
            <option>United States</option>
        </BhSelect>
    </BhField>

    <BhField class="field">
        <BhLabel class="field-label">Delivery notes</BhLabel>
        <BhTextarea name="notes" rows="3" class="field-input field-textarea" />
    </BhField>
</BhFieldset>

@* Rendered HTML:
   <fieldset id="h-xxxx" aria-labelledby="h-xxxx-legend">
       <div class="fieldset-header">
           <div id="h-xxxx-legend" role="legend">Shipping details</div>
           <p class="fieldset-hint">Where should we deliver your order?</p>
       </div>
       <div id="h-xxxx-field-1" class="field">
           <label for="h-xxxx-input-1" id="h-xxxx-label-1">Street address</label>

Disabling a fieldset

Set Disabled="true" on the BhFieldset to disable every form control inside. The fieldset, legend, and all nested fields receive data-disabled for CSS hooks, and the native disabled attribute on the fieldset prevents interaction.

Example

Razor

<BhFieldset Disabled="true" class="fieldset">
    <div class="fieldset-header">
        <BhLegend class="fieldset-legend">Account (locked)</BhLegend>
        <p class="fieldset-hint">Verify your email to edit these fields.</p>
    </div>

    <BhField class="field">
        <BhLabel class="field-label">Username</BhLabel>
        <BhInput type="text" value="alice" class="field-input" />
    </BhField>

    <BhField class="field">
        <BhLabel class="field-label">Email</BhLabel>
        <BhInput type="email" value="alice@example.com" class="field-input" />
    </BhField>
</BhFieldset>

@* The native <fieldset disabled> attribute disables every nested control,
   and data-disabled cascades to the legend and each BhField for styling. *@

CSS

/* Hooks cascaded from BhFieldset Disabled="true" */
.fieldset[data-disabled] {
    background: #fafafa;
    box-shadow: none;
}

.fieldset[data-disabled] .field-input,
.fieldset[data-disabled] .field-input:disabled {
    background: #f4f4f5;
    color: var(--color-muted);
    cursor: not-allowed;
}

.fieldset-legend[data-disabled] {
    color: var(--color-muted);
}

Toggling at runtime

Bind Disabled to a state value to enable or disable the entire group dynamically. Every nested input reflects the change through both the native disabled attribute and data-disabled.

Example

Razor

@code {
    private bool _disabled;
}

<div class="fieldset-toolbar">
    <span class="fieldset-status" data-active="@(!_disabled)">
        <span class="fieldset-status-dot"></span>
        @(_disabled ? "Read-only" : "Editing")
    </span>
    <BhButton OnClick="@(() => _disabled = !_disabled)" class="btn">
        @(_disabled ? "Enable" : "Disable")
    </BhButton>
</div>

<BhFieldset Disabled="_disabled" class="fieldset">
    <div class="fieldset-header">
        <BhLegend class="fieldset-legend">Profile</BhLegend>
        <p class="fieldset-hint">Shown publicly on your profile page.</p>
    </div>

    <BhField class="field">
        <BhLabel class="field-label">Display name</BhLabel>
        <BhInput type="text" class="field-input" />
    </BhField>

    <BhField class="field">
        <BhLabel class="field-label">Bio</BhLabel>
        <BhTextarea rows="2" class="field-input field-textarea" />
    </BhField>
</BhFieldset>

CSS

.fieldset-toolbar {
    display: flex;
    align-items: center;
    justify-content: space-between;
    width: 100%;
    max-width: 28rem;
    margin-bottom: 0.75rem;
    padding: 0.5rem 0.85rem;
    background: #f9fafb;
    border: 1px solid var(--color-border);
    border-radius: var(--radius);
}

.fieldset-status {
    display: inline-flex;
    align-items: center;
    gap: 0.5rem;
    font-size: 0.85rem;
    font-weight: 500;
    color: var(--color-muted);
}

.fieldset-status[data-active="true"]                    { color: #15803d; }
.fieldset-status-dot                                    { width: .5rem; height: .5rem; border-radius: 999px; background: #a1a1af; }
.fieldset-status[data-active="true"] .fieldset-status-dot { background: #22c55e; }
