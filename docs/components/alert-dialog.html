Alert Dialog

A modal dialog that interrupts the user with an important message and expects a deliberate response.

Basic Alert Dialog

Click the trigger to open. Unlike a Dialog, clicking the overlay does not dismiss it — the user must choose Cancel or Action. Focus lands on the Cancel button (the safe choice), is trapped inside, and returns to the trigger on close. Escape closes.

Example

Razor

<BhAlertDialog>
    <BhAlertDialogTrigger class="btn btn-danger">
        Delete account
    </BhAlertDialogTrigger>

    <BhAlertDialogOverlay class="alert-overlay" />
    <BhAlertDialogContent class="alert-content">
        <BhAlertDialogTitle class="alert-title">Are you absolutely sure?</BhAlertDialogTitle>
        <BhAlertDialogDescription class="alert-description">
            This action cannot be undone. This will permanently delete your
            account and remove your data from our servers.
        </BhAlertDialogDescription>

        <div class="alert-actions">
            <BhAlertDialogCancel class="btn">Cancel</BhAlertDialogCancel>
            <BhAlertDialogAction class="btn btn-danger" OnClick="HandleDelete">
                Yes, delete account
            </BhAlertDialogAction>
        </div>
    </BhAlertDialogContent>
</BhAlertDialog>

@code {
    private void HandleDelete() { /* perform the destructive action */ }
}

CSS

/* The library applies minimal default positioning (position:fixed inset:0 on the
   overlay) so consumers can layer the content inside it. Everything else is yours. */

.alert-overlay {
    background: rgba(0, 0, 0, 0.5);
}

.alert-content {
    /* The library centres the content in the viewport by default (position:fixed).
       These rules just give it a surface. */
    width: calc(100vw - 2rem);
    max-width: 28rem;
    background: #fff;
    border-radius: 0.75rem;
    box-shadow: 0 25px 50px -12px rgba(0, 0, 0, 0.25);
    padding: 1.5rem;
    display: flex;
    flex-direction: column;
    gap: 0.85rem;
}

.alert-title       { font-size: 1.1rem; font-weight: 600; color: #18181b; }
.alert-description { font-size: 0.9rem; color: #71717a; }

.alert-actions {
    display: flex;
    justify-content: flex-end;
    gap: 0.5rem;
    margin-top: 0.5rem;
}

.btn-danger {
    background: #dc2626;
    border-color: #dc2626;
    color: #fff;
}

.btn-danger:hover {
    background: #b91c1c;
    border-color: #b91c1c;
}

Controlled state

Drive the open state yourself with Open + OnOpenChange. Useful when an external event (e.g. an unsaved-changes guard) needs to open the alert.

Example

Razor

<BhButton OnClick="() => isOpen = true" class="btn">
    Discard changes
</BhButton>

<BhAlertDialog Open="isOpen" OnOpenChange="v => isOpen = v">
    <BhAlertDialogOverlay class="alert-overlay" />
    <BhAlertDialogContent class="alert-content">
        <BhAlertDialogTitle class="alert-title">Discard changes?</BhAlertDialogTitle>
        <BhAlertDialogDescription class="alert-description">
            You have unsaved changes. If you leave now, they will be lost.
        </BhAlertDialogDescription>

        <div class="alert-actions">
            <BhAlertDialogCancel class="btn">Keep editing</BhAlertDialogCancel>
            <BhAlertDialogAction class="btn btn-danger">Discard</BhAlertDialogAction>
        </div>
    </BhAlertDialogContent>
</BhAlertDialog>

@code {
    private bool isOpen;
}
