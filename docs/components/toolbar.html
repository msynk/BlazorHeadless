Toolbar

A row of buttons, toggles and links that acts as a single tab stop with arrow-key navigation — and zero visual opinion.

Formatting toolbar

BhToolbar renders role="toolbar" as a single tab stop: Tab moves in and out, ← / → travel through every control — toggle-group items included — and Home / End jump to the ends. A multiple BhToggleGroup (bold / italic / strikethrough, aria-pressed) and a single one (alignment, role="radio") share the toolbar's arrow-key navigation with a BhToolbarLink and a BhToolbarButton. Name the toolbar with aria-label.

Example

Razor

<BhToolbar aria-label="Formatting options" class="toolbar">
    <BhToggleGroup Type="BhToggleGroupType.Multiple" @bind-Values="formats"
                   aria-label="Text style" class="toolbar-toggle-group">
        <BhToggleGroupItem Value="bold" aria-label="Bold" class="toolbar-toggle"><strong>B</strong></BhToggleGroupItem>
        <BhToggleGroupItem Value="italic" aria-label="Italic" class="toolbar-toggle"><em>I</em></BhToggleGroupItem>
        <BhToggleGroupItem Value="strike" aria-label="Strikethrough" class="toolbar-toggle"><s>S</s></BhToggleGroupItem>
    </BhToggleGroup>
    <BhToolbarSeparator class="toolbar-separator" />
    <BhToggleGroup @bind-Value="alignment" AllowEmpty="false"
                   aria-label="Text alignment" class="toolbar-toggle-group">
        <BhToggleGroupItem Value="left" aria-label="Align left" class="toolbar-toggle">
            <svg width="16" height="16" viewBox="0 0 16 16" fill="none" aria-hidden="true">
                <path d="M2 3.5h12M2 6.5h8M2 9.5h12M2 12.5h8" stroke="currentColor" stroke-width="1.5" stroke-linecap="round" />
            </svg>
        </BhToggleGroupItem>

            <svg width="16" height="16" viewBox="0 0 16 16" fill="none" aria-hidden="true">
                <path d="M2 3.5h12M4 6.5h8M2 9.5h12M4 12.5h8" stroke="currentColor" stroke-width="1.5" stroke-linecap="round" />
            </svg>
        </BhToggleGroupItem>

            </svg>
        </BhToggleGroupItem>
    </BhToggleGroup>
    <BhToolbarLink href="https://www.w3.org/WAI/ARIA/apg/patterns/toolbar/" target="_blank" rel="noopener"
                   class="toolbar-link">

@code {
    private IReadOnlyCollection<string> formats = ["bold"];
    private string? alignment = "left";
    private string? lastAction;

    private void Log(string action) => lastAction = action;

    private string PreviewStyle =>
        $"text-align: {alignment ?? "left"};"
        + (formats.Contains("bold") ? " font-weight: 600;" : "")
        + (formats.Contains("italic") ? " font-style: italic;" : "")
        + (formats.Contains("strike") ? " text-decoration: line-through;" : "");
}

Disabled buttons stay focusable

Following the APG, a Disabled BhToolbarButton gets aria-disabled="true" and data-disabled instead of the disabled attribute: arrow keys still land on it, so keyboard and screen-reader users can discover it, but clicks are ignored. Paste and Clear stay reachable while the clipboard is empty — cut or copy to enable them.

Example

Razor

<BhToolbar aria-label="Clipboard" class="toolbar">
    <BhToolbarButton OnClick="Cut" class="toolbar-button">✂️ Cut</BhToolbarButton>
    <BhToolbarButton OnClick="Copy" class="toolbar-button">📋 Copy</BhToolbarButton>
    <BhToolbarButton OnClick="Paste" Disabled="@(clipboard is null)" class="toolbar-button">📥 Paste</BhToolbarButton>
    <BhToolbarSeparator class="toolbar-separator" />
    <BhToolbarButton OnClick="ClearClipboard" Disabled="@(clipboard is null)" class="toolbar-button">Clear</BhToolbarButton>
</BhToolbar>

<span class="demo-output">
    Clipboard: <strong>@(clipboard ?? "(empty)")</strong> · Pasted <strong>@pasteCount</strong>×
</span>

@code {
    private string? clipboard;
    private int pasteCount;

    private void Cut() => clipboard = "“Selected text” (cut)";
    private void Copy() => clipboard = "“Selected text”";
    private void Paste() => pasteCount++;
    private void ClearClipboard() => clipboard = null;
}

Vertical orientation

Orientation="BhRovingOrientation.Vertical" switches navigation to ↑ / ↓ and sets aria-orientation and data-orientation on the toolbar; its separators flip to horizontal. The tool picker is a single-select toggle group (AllowEmpty="false" keeps one tool active), and Undo / Redo disable themselves — while staying focusable — when their stack is empty.

Example

Razor

<div class="toolbar-canvas">
    <BhToolbar Orientation="BhRovingOrientation.Vertical" aria-label="Drawing tools" class="toolbar">
        <BhToggleGroup @bind-Value="tool" AllowEmpty="false" aria-label="Tool" class="toolbar-toggle-group">
            <BhToggleGroupItem Value="Select" aria-label="Select" title="Select" class="toolbar-toggle">↖</BhToggleGroupItem>
            <BhToggleGroupItem Value="Pen" aria-label="Pen" title="Pen" class="toolbar-toggle">✎</BhToggleGroupItem>
            <BhToggleGroupItem Value="Shape" aria-label="Shape" title="Shape" class="toolbar-toggle">▭</BhToggleGroupItem>
            <BhToggleGroupItem Value="Text" aria-label="Text" title="Text" class="toolbar-toggle">T</BhToggleGroupItem>
        </BhToggleGroup>
        <BhToolbarSeparator class="toolbar-separator" />
        <BhToolbarButton OnClick="Undo" Disabled="@(undoDepth == 0)" aria-label="Undo" title="Undo"
                         class="toolbar-button">↶</BhToolbarButton>
        <BhToolbarButton OnClick="Redo" Disabled="@(redoDepth == 0)" aria-label="Redo" title="Redo"
                         class="toolbar-button">↷</BhToolbarButton>
    </BhToolbar>

    <div class="toolbar-stage">
        <strong>@tool</strong>
        <span>Undo stack: @undoDepth · Redo stack: @redoDepth</span>
    </div>
</div>

@code {
    private string? tool = "Pen";
    private int undoDepth = 3;
    private int redoDepth;

    private void Undo() { undoDepth--; redoDepth++; }
    private void Redo() { redoDepth--; undoDepth++; }
}
