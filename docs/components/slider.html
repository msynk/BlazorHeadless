Slider

Pick a value — or a range with several thumbs — within a minimum and maximum, by pointer or keyboard.

Single value

Follows the WAI-ARIA Slider pattern: each BhSliderThumb is a role="slider" with aria-valuenow/min/max. Click or drag anywhere on the track, or focus the thumb and use the arrow keys (± Step), PageUp / PageDown or Shift+arrows (± LargeStep) and Home / End.

Example

Razor

<BhSlider @bind-Value="volume" class="slider">
    <BhSliderTrack class="slider-track">
        <BhSliderRange class="slider-range" />
    </BhSliderTrack>
    <BhSliderThumb class="slider-thumb" aria-label="Volume" />
</BhSlider>

<p class="slider-value">Volume: <strong>@volume</strong></p>

@code {
    private double volume = 50;
}

CSS

/* All styles are consumer-authored — the library ships zero CSS */

/* BhSlider only adds its default inline layout when you pass neither class
   nor style, so a styled root must be position: relative itself — thumbs are
   absolutely positioned against it. */
.slider {
    position: relative;
    display: flex;
    align-items: center;
    width: 100%;
    max-width: 20rem;
    height: 1.25rem;
    touch-action: none;   /* keep touch drags on the slider */
    user-select: none;
    cursor: pointer;
}

/* Track (inline: position: relative; flex-grow: 1) */
.slider-track {
    border-radius: 999px;
    background: #e4e4e7;
}

.slider-track[data-orientation="horizontal"] { height: 0.375rem; }

/* Range (inline: position: absolute + two edges) */
.slider-range {
    inset: 0;             /* inline left/right (or top/bottom) override two of these */
    border-radius: inherit;
    background: #2563eb;
}

/* Thumb (inline: position: absolute + left % + translate) */
.slider-thumb {
    display: block;
    box-sizing: border-box;
    width: 1.25rem;
    height: 1.25rem;
    border: 2px solid #2563eb;
    border-radius: 999px;
    background: #fff;
    box-shadow: 0 1px 3px rgba(24, 24, 27, 0.25);
    cursor: grab;
    outline: none;
    transition: box-shadow 120ms ease;
}

/* Center the thumb across the track (the inline transform handles the other axis). */
.slider-thumb[data-orientation="horizontal"] { top: 50%; margin-top: -0.625rem; }

.slider-thumb:hover         { box-shadow: 0 0 0 5px rgba(37, 99, 235, 0.12); }
.slider-thumb:focus-visible { box-shadow: 0 0 0 4px rgba(37, 99, 235, 0.35); }
.slider-thumb[data-dragging] {
    cursor: grabbing;
    box-shadow: 0 0 0 6px rgba(37, 99, 235, 0.2);
}

/* Demo layout */
.slider-demo { display: grid; gap: 1rem; width: 100%; }

.slider-value { margin: 0; font-size: 0.85rem; color: #71717a; }
.slider-value strong { color: #18181b; font-weight: 600; font-variant-numeric: tabular-nums; }

<p class="m-0 text-sm text-zinc-500">Volume: <strong class="font-semibold tabular-nums text-zinc-900">@volume</strong></p>

}

Range with two thumbs

Bind @@bind-Values and render one thumb per value (Multi-Thumb Slider pattern). Thumbs can't cross; MinStepsBetweenThumbs keeps them apart. ValueText formats aria-valuetext so screen readers hear "$200" instead of "200". BhSliderRange fills the span between the thumbs.

Example

Razor

<BhSlider @bind-Values="price" Max="1000" Step="10" MinStepsBetweenThumbs="10"
          ValueText="@(v => $"${v:N0}")" class="slider">
    <BhSliderTrack class="slider-track">
        <BhSliderRange class="slider-range" />
    </BhSliderTrack>
    <BhSliderThumb class="slider-thumb" aria-label="Minimum price" />
    <BhSliderThumb class="slider-thumb" aria-label="Maximum price" />
</BhSlider>

<p class="slider-value">Price: <strong>@($"${price[0]:N0} – ${price[1]:N0}")</strong></p>

@code {
    private IReadOnlyList<double> price = [200, 600];
}

Step, LargeStep and a thumb Template

Step="0.5" snaps values to half degrees; LargeStep="5" sets the PageUp / PageDown / Shift+arrow jump (default: a tenth of the range). BhSliderThumb's Template receives the thumb's value — used here for a value bubble.

Example

Razor

<BhSlider @bind-Value="temperature" Min="10" Max="30" Step="0.5" LargeStep="5"
          ValueText="@(v => $"{v:0.0} °C")" class="slider slider-bubbled">
    <BhSliderTrack class="slider-track">
        <BhSliderRange class="slider-range" />
    </BhSliderTrack>
    <BhSliderThumb class="slider-thumb" aria-label="Thermostat">
        <Template Context="current">
            <span class="slider-bubble">@current.ToString("0.0")°</span>
        </Template>
    </BhSliderThumb>
</BhSlider>

<p class="slider-value">Target: <strong>@temperature.ToString("0.0") °C</strong></p>

@code {
    private double temperature = 21.5;
}

Vertical orientation

Orientation="BhOrientation.Vertical" measures the pointer along the height and sets aria-orientation; ↑ / → increase, ↓ / ← decrease. Each band is uncontrolled via DefaultValue, with a negative Min.

Example

Razor

<div class="slider-eq">
    @foreach (var band in bands)
    {
        <div class="slider-eq-band">
            <BhSlider Orientation="BhOrientation.Vertical" Min="-12" Max="12"
                      DefaultValue="band.Gain" ValueText="@(v => $"{v:+0;-0;0} dB")"
                      class="slider">
                <BhSliderTrack class="slider-track">
                    <BhSliderRange class="slider-range" />
                </BhSliderTrack>
                <BhSliderThumb class="slider-thumb" aria-label="@band.Name" />
            </BhSlider>
            <span class="slider-eq-label" aria-hidden="true">@band.Name</span>
        </div>
    }
</div>

@code {
    private readonly (string Name, double Gain)[] bands = [("Bass", 4), ("Mid", -2), ("Treble", 6)];
}

In a field, with OnValueCommit

Inside a BhField the thumb is labelled by BhLabel (aria-labelledby) and described by BhDescription; clicking the label focuses the thumb. @@bind-Value updates live while dragging, whereas OnValueCommit fires once on pointer up or per key press — the place to save.

Example

Razor

<BhField class="slider-field">
    <BhLabel class="slider-label">Brightness</BhLabel>
    <BhSlider @bind-Value="brightness" OnValueCommit="v => committed = v[0]"
              ValueText="@(v => $"{v}%")" class="slider">
        <BhSliderTrack class="slider-track">
            <BhSliderRange class="slider-range" />
        </BhSliderTrack>
        @* No aria-label needed: the field's label names the thumb. *@
        <BhSliderThumb class="slider-thumb" />
    </BhSlider>
    <BhDescription class="slider-description">Saved when you release the thumb or press a key.</BhDescription>
</BhField>

<p class="slider-value">
    Live: <strong>@brightness%</strong> · Committed: <strong>@committed%</strong>
</p>

@code {
    private double brightness = 70;
    private double committed = 70;
}

Disabled

Disabled="true" ignores pointer and keys, takes the thumbs out of the tab order (tabindex="-1", aria-disabled="true") and adds data-disabled to every part. The range below is uncontrolled via DefaultValues.

Example

Razor

<BhSlider DefaultValue="40" Disabled="true" class="slider">
    <BhSliderTrack class="slider-track">
        <BhSliderRange class="slider-range" />
    </BhSliderTrack>
    <BhSliderThumb class="slider-thumb" aria-label="Locked volume" />
