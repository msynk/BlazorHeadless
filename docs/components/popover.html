Popover

A non-modal floating panel with focus management, Escape-to-close, and group coordination.

Basic Popover

Click the button to open the panel. Focus moves into the panel automatically. Press Escape or click outside to close — focus returns to the button. Unlike a Dialog, the rest of the page stays interactive.

Example

Razor

<BhPopover class="popover">
    <BhPopoverButton class="popover-button" Context="b">
        Learn more
        <span class="popover-chevron @(b.IsOpen ? "open" : "")">▾</span>
    </BhPopoverButton>
    <BhPopoverPanel class="popover-panel" Context="p">
        <h3 class="popover-title">BlazorHeadless</h3>
        <p class="popover-body">
            A headless component library for Blazor. Zero styles, full accessibility,
            complete control over your design.
        </p>
        <a href="https://github.com" target="_blank" class="popover-link">
            View on GitHub →
        </a>
        @* BhPopoverButton inside the panel acts as a Close button *@
        <BhPopoverButton class="popover-close-btn">Close</BhPopoverButton>
    </BhPopoverPanel>
</BhPopover>

Popover Group (mutual exclusion)

Wrap multiple popovers in an BhPopoverGroup so opening one automatically closes the others. Useful for navigation bars.

Controlled

Drive the open state externally with Open and OnOpenChange. The button below opens or closes the popover programmatically.

Example

Razor

<div style="display:flex; flex-direction:column; gap:1rem; align-items:flex-start;">
    <div class="demo-row">
        <BhButton OnClick="ToggleControlled" class="btn">
            Toggle from outside
        </BhButton>
        <span class="demo-output">Open: <strong>@controlledOpen.ToString().ToLowerInvariant()</strong></span>
    </div>

    <BhPopover Open="controlledOpen"
              OnOpenChange="v => controlledOpen = v"
              class="popover">
        <BhPopoverButton class="popover-button" Context="b">
            Internal trigger
            <span class="popover-chevron @(b.IsOpen ? "open" : "")">▾</span>
        </BhPopoverButton>
        <BhPopoverPanel class="popover-panel">
            <p class="popover-body">
                Either trigger updates the same state — fully controlled.
            </p>
        </BhPopoverPanel>
    </BhPopover>
</div>

@code {
    private bool controlledOpen;

    private void ToggleControlled() => controlledOpen = !controlledOpen;
}

Anchor Positioning

Set Anchor on BhPopoverPanel to automatically position the panel relative to the button. The panel uses position: fixed, flips when there's not enough space, and auto-updates on scroll/resize. No position: relative on the parent or position: absolute on the panel needed.

Example

Razor

@* Anchor positions the panel relative to the button automatically.
   Supports all sides: top, right, bottom, left — with start/end alignment. *@

<BhPopover class="popover-anchored">
    <BhPopoverButton class="popover-button" Context="b">
        Bottom Start ▾
    </BhPopoverButton>
    <BhPopoverPanel Anchor="@(new BhAnchorOptions { To = "bottom start", Gap = 8 })"
                   class="popover-panel-anchored" Context="p">
        <p>This panel is anchored with auto-flip and shift.</p>
    </BhPopoverPanel>
</BhPopover>

@* Available placements: top, top start, top end,
   bottom, bottom start, bottom end,
   left, left start, left end,
   right, right start, right end *@

        </div>
