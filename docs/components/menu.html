Menu

An accessible dropdown menu with keyboard navigation, typeahead, and zero visual opinion.

Basic Menu

Click the button or press Space / Enter / arrow keys to open. Use Up / Down to navigate, Home / End to jump, Enter / Space to activate, Escape to close. Type a letter to jump to the first matching item. ARIA wiring (aria-haspopup="menu", aria-expanded, aria-activedescendant) is handled automatically.

Example

Razor

<BhMenu class="menu">
    <BhMenuButton class="menu-button" Context="b">
        Options
        <span class="menu-chevron @(b.IsOpen ? "open" : "")">▾</span>
    </BhMenuButton>
    <BhMenuItems class="menu-items">
        <BhMenuItem OnClick='@(() => Log("Edit"))'      class="menu-item" Label="Edit">Edit</BhMenuItem>
        <BhMenuItem OnClick='@(() => Log("Duplicate"))' class="menu-item" Label="Duplicate">Duplicate</BhMenuItem>
        <BhMenuItem OnClick='@(() => Log("Archive"))'   class="menu-item" Label="Archive">Archive</BhMenuItem>
        <BhMenuItem OnClick='@(() => Log("Delete"))'    class="menu-item" Label="Delete">Delete</BhMenuItem>
    </BhMenuItems>
</BhMenu>

<span class="demo-output">Last action: <strong>@(lastAction ?? "(none)")</strong></span>

@code {
    private string? lastAction;

    private void Log(string action) => lastAction = action;
}

Disabled Items

Set Disabled="true" on individual items. Disabled items receive data-disabled for CSS, are skipped by arrow-key nav, and are ignored by typeahead.

Example

Razor

<BhMenu class="menu">
    <BhMenuButton class="menu-button" Context="b">
        Account
        <span class="menu-chevron @(b.IsOpen ? "open" : "")">▾</span>
    </BhMenuButton>
    <BhMenuItems class="menu-items">
        <BhMenuItem OnClick='@(() => Log("Profile"))'  class="menu-item" Label="Profile">Profile</BhMenuItem>
        <BhMenuItem OnClick='@(() => Log("Settings"))' class="menu-item" Label="Settings">Settings</BhMenuItem>
        <BhMenuItem OnClick='@(() => Log("Billing"))'  class="menu-item" Label="Billing"
                   Disabled="true">Billing (unavailable)</BhMenuItem>
        <BhMenuItem OnClick='@(() => Log("Sign out"))' class="menu-item" Label="Sign out">Sign out</BhMenuItem>
    </BhMenuItems>
</BhMenu>

CSS

/* Hooks emitted when Disabled="true" on an item */
.menu-item[data-disabled] {
    opacity: 0.4;
    cursor: not-allowed;
}

/* Arrow-key navigation and typeahead skip disabled items automatically. */

Rich item content

Items can contain any markup. Use the data-active hook to drive the highlighted style and provide a Label string so typeahead still works when the content is rich.

Sections and dividers

Group related items with a plain <li> divider or a section heading. These are regular HTML elements — the menu component doesn't need to know about them.

Example

Razor

    <BhMenuButton class="menu-button" Context="b">
        More
        <span class="menu-chevron @(b.IsOpen ? "open" : "")">▾</span>
    </BhMenuButton>
    <BhMenuItems class="menu-items">
        <li class="menu-section-label" role="presentation">View</li>
        <BhMenuItem OnClick='@(() => Log("Zoom in"))'     class="menu-item" Label="Zoom in">Zoom in</BhMenuItem>
        <BhMenuItem OnClick='@(() => Log("Zoom out"))'    class="menu-item" Label="Zoom out">Zoom out</BhMenuItem>

Anchor Positioning

Set Anchor on BhMenuItems to automatically position the dropdown relative to the button. The panel uses position: fixed and auto-updates on scroll/resize. It flips to the opposite side if there's not enough space, and shifts to stay within the viewport. CSS custom properties --button-width, --anchor-gap are exposed on the panel.

Example

Razor

@* Anchor positions the dropdown relative to the button automatically.
   It flips to the opposite side if there's not enough space. *@

<div style="display:flex; gap:1.5rem; flex-wrap:wrap; align-items:flex-start;">
    <BhMenu class="menu">
        <BhMenuButton class="menu-button" Context="b">
            Bottom Start
            <span class="menu-chevron @(b.IsOpen ? "open" : "")">▾</span>
        </BhMenuButton>
        <BhMenuItems Anchor="@(new BhAnchorOptions { To = "bottom start", Gap = 4 })"
                    class="menu-items-anchored">
            <BhMenuItem OnClick="@(() => Log("Edit"))"      class="menu-item" Label="Edit">Edit</BhMenuItem>
            <BhMenuItem OnClick="@(() => Log("Duplicate"))" class="menu-item" Label="Duplicate">Duplicate</BhMenuItem>
            <BhMenuItem OnClick="@(() => Log("Archive"))"   class="menu-item" Label="Archive">Archive</BhMenuItem>
        </BhMenuItems>
    </BhMenu>

    <BhMenu class="menu">
        <BhMenuButton class="menu-button" Context="b">
            Bottom End
            <span class="menu-chevron @(b.IsOpen ? "open" : "")">▾</span>
        </BhMenuButton>
        <BhMenuItems Anchor="@(new BhAnchorOptions { To = "bottom end", Gap = 4 })"
                    class="menu-items-anchored">
            <BhMenuItem OnClick="@(() => Log("Cut"))"   class="menu-item" Label="Cut">Cut</BhMenuItem>
            <BhMenuItem OnClick="@(() => Log("Copy"))"  class="menu-item" Label="Copy">Copy</BhMenuItem>
            <BhMenuItem OnClick="@(() => Log("Paste"))" class="menu-item" Label="Paste">Paste</BhMenuItem>
        </BhMenuItems>
    </BhMenu>

    @* Use --button-width to match the dropdown width to the trigger *@
    <BhMenu class="menu">
        <BhMenuButton class="menu-button" Context="b">
            Match Width
            <span class="menu-chevron @(b.IsOpen ? "open" : "")">▾</span>
        </BhMenuButton>
        <BhMenuItems Anchor="@(new BhAnchorOptions { To = "bottom", Gap = 4 })"
                    class="menu-items-anchored menu-items-match-width">
            <BhMenuItem OnClick="@(() => Log("Option A"))" class="menu-item" Label="Option A">Option A</BhMenuItem>
            <BhMenuItem OnClick="@(() => Log("Option B"))" class="menu-item" Label="Option B">Option B</BhMenuItem>
            <BhMenuItem OnClick="@(() => Log("Option C"))" class="menu-item" Label="Option C">Option C</BhMenuItem>
        </BhMenuItems>
    </BhMenu>
</div>

.menu-items-match-width {
    min-width: unset;
    width: var(--button-width);
}

Polymorphic items

Set As="a" on an item to render it as an anchor tag — useful for navigation links inside a menu. The item still participates in keyboard nav and receives all the ARIA attributes.

Example

Razor

<BhMenu class="menu">
