Toggle / Toggle Group

Two-state buttons on their own, or grouped for formatting, alignment and view switchers.

Toggle button

BhToggle is the APG Button pattern's toggle variant: a native <button> with aria-pressed and data-state="on|off". Space / Enter or a click flips it. Use @@bind-Pressed, DefaultPressed for uncontrolled use, and Disabled.

Example

Razor

<BhToggle aria-label="Bold" class="toggle-btn"><strong>B</strong></BhToggle>

<BhToggle @bind-Pressed="muted" class="toggle-btn">Mute</BhToggle>

<BhToggle DefaultPressed="true" Disabled="true" class="toggle-btn">Pinned</BhToggle>

<p class="toggle-output">Muted: <strong>@(muted ? "yes" : "no")</strong></p>

@code {
    private bool muted;
}

State-aware content with Template

When the content depends on the pressed state, use Template instead of child content — its context is the bool pressed state. Keep the label itself constant (APG): only the icon swaps here, aria-pressed conveys the state.

Example

Razor

<BhToggle DefaultPressed="true" class="toggle-btn">
    <Template Context="pressed">
        <span class="toggle-icon" aria-hidden="true">@(pressed ? "★" : "☆")</span>
        Star
    </Template>
</BhToggle>

<BhToggle class="toggle-btn">
    <Template Context="pressed">
        <span class="toggle-icon" aria-hidden="true">@(pressed ? "✓" : "+")</span>
        Follow
    </Template>
</BhToggle>

Multiple: text formatting

Type="BhToggleGroupType.Multiple" renders a role="group" of aria-pressed buttons bound with @@bind-Values. The group is a single tab stop: ← / → move focus (wrapping), Home / End jump, Space / Enter toggle.

Example

Razor

<BhToggleGroup Type="BhToggleGroupType.Multiple" @bind-Values="textStyles"
               aria-label="Text formatting" class="toggle-group">
    <BhToggleGroupItem Value="bold" aria-label="Bold" class="toggle-item"><strong>B</strong></BhToggleGroupItem>
    <BhToggleGroupItem Value="italic" aria-label="Italic" class="toggle-item"><em>I</em></BhToggleGroupItem>
    <BhToggleGroupItem Value="underline" aria-label="Underline" class="toggle-item"><u>U</u></BhToggleGroupItem>
    <BhToggleGroupItem Value="strike" aria-label="Strikethrough" class="toggle-item"><s>S</s></BhToggleGroupItem>
</BhToggleGroup>

<p class="toggle-preview" style="@PreviewStyle()">The quick brown fox jumps over the lazy dog.</p>

<p class="toggle-output">
    Values: <strong>@(textStyles.Count == 0 ? "none" : string.Join(", ", textStyles))</strong>
</p>

@code {
    private IReadOnlyCollection<string> textStyles = ["bold"];

    private string PreviewStyle()
    {
        var decorations = textStyles
            .Where(s => s is "underline" or "strike")
            .Select(s => s == "strike" ? "line-through" : s)
            .ToList();
        return $"font-weight: {(textStyles.Contains("bold") ? 700 : 400)}; " +
               $"font-style: {(textStyles.Contains("italic") ? "italic" : "normal")}; " +
               $"text-decoration: {(decorations.Count > 0 ? string.Join(" ", decorations) : "none")}";
    }
}

Single: alignment

The default Type="BhToggleGroupType.Single" behaves like a radio group (role="radiogroup" of role="radio" items with aria-checked); the pressed item is the tab stop. Clicking the pressed item normally clears the value — AllowEmpty="false" keeps one alignment selected at all times.

Example

Razor

               aria-label="Text alignment" class="toggle-group">

Vertical orientation

Orientation="BhRovingOrientation.Vertical" switches navigation to ↑ / ↓ and sets data-orientation="vertical" for styling. This group is uncontrolled (DefaultValue) and each item's Template receives its pressed state to draw a check mark.

Example

Razor

<BhToggleGroup Orientation="BhRovingOrientation.Vertical" DefaultValue="week"
               aria-label="Calendar view" class="toggle-group">
    @foreach (var view in views)
    {
        <BhToggleGroupItem Value="@view.ToLowerInvariant()" class="toggle-item">
            <Template Context="isOn">
                <span class="toggle-check" aria-hidden="true">@(isOn ? "✓" : "")</span>
                @view
            </Template>
        </BhToggleGroupItem>
    }
</BhToggleGroup>

@code {
    private readonly string[] views = ["Day", "Week", "Month", "Year"];
}

                           class="inline-flex h-8 cursor-pointer items-center justify-start gap-2 rounded-md px-2.5 text-sm font-medium text-zinc-600 outline-none transition hover:bg-zinc-200 hover:text-zinc-900 focus-visible:ring-2 focus-visible:ring-blue-600 data-[state=on]:bg-white data-[state=on]:text-blue-600 data-[state=on]:shadow-sm data-[state=on]:hover:bg-white">
            <Template Context="isOn">
                <span class="inline-block w-4 text-blue-600" aria-hidden="true">@(isOn ? "✓" : "")</span>
                @view
            </Template>
        </BhToggleGroupItem>
    }
</BhToggleGroup>

@code {
    private readonly string[] views = ["Day", "Week", "Month", "Year"];
}

Disabled items

Disabled="true" on an item renders the native disabled attribute and data-disabled; arrow keys skip it. On the group it disables every item.

Example

Razor

<BhToggleGroup @bind-Value="size" aria-label="Size" class="toggle-group">
    <BhToggleGroupItem Value="s" class="toggle-item">S</BhToggleGroupItem>
    <BhToggleGroupItem Value="m" class="toggle-item">M</BhToggleGroupItem>
    <BhToggleGroupItem Value="l" class="toggle-item">L</BhToggleGroupItem>
    <BhToggleGroupItem Value="xl" Disabled="true" class="toggle-item">XL</BhToggleGroupItem>
</BhToggleGroup>

<BhToggleGroup DefaultValue="m" Disabled="true" aria-label="Size (sold out)" class="toggle-group">
    <BhToggleGroupItem Value="s" class="toggle-item">S</BhToggleGroupItem>
    <BhToggleGroupItem Value="m" class="toggle-item">M</BhToggleGroupItem>
    <BhToggleGroupItem Value="l" class="toggle-item">L</BhToggleGroupItem>
</BhToggleGroup>

@code {
    private string? size = "m";
}
