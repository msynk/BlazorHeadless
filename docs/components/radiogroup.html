Radio Group

An accessible single-select group with roving tabindex and full keyboard support.

Basic Radio Group

Click a radio or use Up / Down arrow keys (Left / Right when horizontal) to navigate and select. Disabled radios are skipped. aria-checked, role="radiogroup", and role="radio" are wired automatically.

Example

Razor

<BhRadioGroup DefaultValue="medium" class="radio-group">
    <label class="radio-label">
        <BhRadio Value="small" class="radio" Context="r">
            @if (r.IsChecked) { <span class="radio-dot"></span> }
        </BhRadio>
        <span>Small</span>
    </label>
    <label class="radio-label">
        <BhRadio Value="medium" class="radio" Context="r">
            @if (r.IsChecked) { <span class="radio-dot"></span> }
        </BhRadio>
        <span>Medium</span>
    </label>
    <label class="radio-label">
        <BhRadio Value="large" class="radio" Context="r">
            @if (r.IsChecked) { <span class="radio-dot"></span> }
        </BhRadio>
        <span>Large</span>
    </label>
</BhRadioGroup>

Horizontal Orientation

Disabled Radio

Set Disabled="true" on individual radios. Arrow-key navigation skips disabled options. Set Disabled="true" on the root group to disable everything at once.

Example

Razor

<BhRadioGroup DefaultValue="standard" class="radio-group">
    <label class="radio-label">
        <BhRadio Value="standard" class="radio" Context="r">
            @if (r.IsChecked) { <span class="radio-dot"></span> }
        </BhRadio>
        <span>Standard shipping (3–5 days)</span>
    </label>
    <label class="radio-label">
        <BhRadio Value="express" class="radio" Context="r">
            @if (r.IsChecked) { <span class="radio-dot"></span> }
        </BhRadio>
        <span>Express shipping (1–2 days)</span>
    </label>
    <label class="radio-label">
        <BhRadio Value="same-day" Disabled="true" class="radio" Context="r">
            @if (r.IsChecked) { <span class="radio-dot"></span> }
        </BhRadio>
        <span>Same-day shipping (unavailable in your region)</span>
    </label>
</BhRadioGroup>

CSS

/* Hooks emitted when Disabled="true" on a radio (or the root group) */
.radio[data-disabled] {
    opacity: 0.5;
    cursor: not-allowed;
}

/* Arrow-key navigation skips disabled radios automatically. */

Card-style options

Because the radio is the only interactive element, you can place rich content (titles, descriptions, prices) inside the <label> wrapper and use the data-state="checked" hook to highlight the selected card.

Controlled

Drive selection externally with Value and OnValueChange.

Example

Razor

<div style="display:flex; flex-direction:column; gap:1rem; width:100%">
    <div class="demo-row">
        <BhButton OnClick='() => selectedColor = "red"' class="btn">Red</BhButton>
        <BhButton OnClick='() => selectedColor = "green"' class="btn">Green</BhButton>
        <BhButton OnClick='() => selectedColor = "blue"' class="btn">Blue</BhButton>
        <span class="demo-output">Selected: <strong>@(selectedColor ?? "(none)")</strong></span>
    </div>

    <BhRadioGroup Value="@selectedColor"
                 OnValueChange="v => selectedColor = v"
                 class="radio-group">
        <label class="radio-label">
            <BhRadio Value="red" class="radio" Context="r">

Form Submission

Set Name on the group to render a hidden <input> carrying the selected value, so plain HTML form posts include the group's selection.

Example

Razor

<form @onsubmit="HandleFormSubmit"
      @onsubmit:preventDefault="true"
      style="display:flex; flex-direction:column; gap:0.75rem; align-items:flex-start;">
    <BhRadioGroup Name="size" DefaultValue="m" class="radio-group">
        <label class="radio-label">
            <BhRadio Value="s" class="radio" Context="r">
                @if (r.IsChecked) { <span class="radio-dot"></span> }
            </BhRadio>
            <span>Small</span>
        </label>
        <label class="radio-label">
            <BhRadio Value="m" class="radio" Context="r">
                @if (r.IsChecked) { <span class="radio-dot"></span> }
            </BhRadio>
            <span>Medium</span>
        </label>
        <label class="radio-label">
            <BhRadio Value="l" class="radio" Context="r">
                @if (r.IsChecked) { <span class="radio-dot"></span> }
            </BhRadio>
            <span>Large</span>
        </label>
    </BhRadioGroup>

    <button type="submit" class="btn btn-primary">Submit</button>

    @if (lastSubmitted is not null)
    {
        <span class="demo-output">@lastSubmitted</span>
    }
</form>

@code {
    private string? lastSubmitted;

    private void HandleFormSubmit()
    {
        lastSubmitted = "(submitted — the form posts size=<selected value>)";
    }
}

@* The group renders a single hidden input — posts:  size=<selected value> *@
