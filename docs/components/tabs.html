Tabs

An accessible tab group with roving tabindex, full keyboard navigation, and zero visual opinion.

Basic Tabs

Click a tab or use Left / Right arrow keys, Home, and End to navigate. Disabled tabs are skipped automatically. ARIA roles, aria-selected, aria-controls, and aria-labelledby are wired automatically.

Example

Razor

<BhTabGroup class="tabs">
    <BhTabList class="tab-list">
        <BhTab class="tab">Account</BhTab>
        <BhTab class="tab">Profile</BhTab>
        <BhTab class="tab">Notifications</BhTab>
    </BhTabList>
    <BhTabPanels class="tab-panels">
        <BhTabPanel class="tab-panel">
            <h3>Account</h3>
            <p>Manage your account settings and preferences.</p>
        </BhTabPanel>
        <BhTabPanel class="tab-panel">
            <h3>Profile</h3>
            <p>Update your public profile information.</p>
        </BhTabPanel>
        <BhTabPanel class="tab-panel">
            <h3>Notifications</h3>
            <p>Choose what alerts you'd like to receive.</p>
        </BhTabPanel>
    </BhTabPanels>
</BhTabGroup>

}

    display: flex;

}

    all: unset;
    padding: 0.6rem 1rem;
    font-size: 0.9rem;

    color: #71717a;

    border-bottom: 2px solid transparent;
    transition: color 150ms ease, border-color 150ms ease;

}

Vertical Orientation

Set Vertical="true" to render tabs in a column. Arrow-key navigation switches to Up / Down, and the root and tablist both emit data-orientation="vertical" for CSS layout hooks.

Example

Razor

<BhTabGroup Vertical="true" class="tabs tabs-vertical">
    <BhTabList class="tab-list">
        <BhTab class="tab">General</BhTab>
        <BhTab class="tab">Security</BhTab>
        <BhTab class="tab">Integrations</BhTab>
    </BhTabList>
    <BhTabPanels class="tab-panels">
        <BhTabPanel class="tab-panel">
            <h3>General</h3>
            <p>Application-wide settings.</p>
        </BhTabPanel>
        <BhTabPanel class="tab-panel">
            <h3>Security</h3>
            <p>Two-factor auth, sessions, and audit log.</p>
        </BhTabPanel>
        <BhTabPanel class="tab-panel">
            <h3>Integrations</h3>
            <p>Connect third-party services.</p>
        </BhTabPanel>
    </BhTabPanels>
</BhTabGroup>

CSS

/* Reuses .tabs / .tab / .tab-panels styles from the Basic demo.
   When Vertical="true" the root and tablist receive data-orientation="vertical",
   which we use to flip the layout. */
.tabs[data-orientation="vertical"] {
    flex-direction: row;
    align-items: flex-start;
    gap: 1.5rem;
}

.tabs[data-orientation="vertical"] .tab-list {
    flex-direction: column;
    border-bottom: none;
    border-right: 1px solid #e4e4e7;
    min-width: 12rem;
}

.tabs[data-orientation="vertical"] .tab {
    border-bottom: none;
    border-right: 2px solid transparent;
    text-align: start;
}

.tabs[data-orientation="vertical"] .tab[data-state="active"] {
    border-right-color: #2563eb;
    border-bottom-color: transparent;
}

.tabs[data-orientation="vertical"] .tab-panels { flex: 1 1 auto; }

Manual Activation

With Manual="true" arrow keys only move keyboard focus; press Space or Enter to activate the focused tab. Useful when activating a tab is expensive (loads data, navigates, etc.) — try it: focus a tab, then arrow without selecting.

Disabled Tab

Set Disabled="true" on individual tabs. Arrow-key navigation skips disabled tabs, and the disabled tab still receives data-disabled for CSS hooks.

Example

Razor

<BhTabGroup class="tabs">
    <BhTabList class="tab-list">
        <BhTab class="tab">Free</BhTab>
        <BhTab class="tab">Pro</BhTab>
        <BhTab class="tab" Disabled="true">Enterprise (coming soon)</BhTab>
    </BhTabList>
    <BhTabPanels class="tab-panels">
        <BhTabPanel class="tab-panel"><p>Free plan features.</p></BhTabPanel>
        <BhTabPanel class="tab-panel"><p>Pro plan features.</p></BhTabPanel>
        <BhTabPanel class="tab-panel"><p>Enterprise plan features.</p></BhTabPanel>
    </BhTabPanels>
</BhTabGroup>

CSS

/* Hooks emitted when a tab is disabled */
.tab[data-disabled] {
    opacity: 0.4;
    cursor: not-allowed;
}

/* Arrow-key navigation skips disabled tabs automatically — no JS needed. */

Render Context (state-driven content)

BhTab exposes a BhTabRenderContext via Context="t" so you can render badges, icons, or active indicators driven by the tab's own state.

Example

Razor

<BhTabGroup class="tabs">
    <BhTabList class="tab-list">
        <BhTab class="tab" Context="t">
            <span>Messages</span>
            <span class="badge @(t.IsSelected ? "badge-active" : "")">12</span>
        </BhTab>
        <BhTab class="tab" Context="t">
            <span>Mentions</span>
            <span class="badge @(t.IsSelected ? "badge-active" : "")">3</span>
        </BhTab>
        <BhTab class="tab" Context="t">
            <span>All</span>
        </BhTab>
    </BhTabList>
    <BhTabPanels class="tab-panels">
        <BhTabPanel class="tab-panel"><p>Direct messages</p></BhTabPanel>
        <BhTabPanel class="tab-panel"><p>Mentions of you</p></BhTabPanel>
        <BhTabPanel class="tab-panel"><p>Everything together</p></BhTabPanel>
    </BhTabPanels>
</BhTabGroup>

CSS

/* The Tab render-prop context exposes IsSelected so you can style children
   based on the parent tab's state. */
.badge {
    margin-left: 0.5rem;
    padding: 0.05rem 0.4rem;
    background: #e4e4e7;
    color: #52525b;
    border-radius: 999px;
    font-size: 0.7rem;
    font-weight: 600;
}

.badge-active {
    background: #2563eb;
    color: #fff;
}

Controlled

Drive selection externally with SelectedIndex and OnSelectedIndexChange. The buttons below select tabs programmatically.

Example

Razor

<div style="display:flex; flex-direction:column; gap:1rem; width:100%">
    <div class="demo-row">
        @for (var i = 0; i < 3; i++)
        {
            var captured = i;
            <BhButton OnClick="() => selectedIndex = captured"
                     class="@(selectedIndex == captured ? "btn btn-primary" : "btn")">
                Select tab @(captured + 1)
            </BhButton>
        }
        <span class="demo-output">SelectedIndex: <strong>@selectedIndex</strong></span>
    </div>

    <BhTabGroup SelectedIndex="@selectedIndex"
               OnSelectedIndexChange="i => selectedIndex = i"
               class="tabs">
        <BhTabList class="tab-list">
            <BhTab class="tab">Tab 1</BhTab>
            <BhTab class="tab">Tab 2</BhTab>
            <BhTab class="tab">Tab 3</BhTab>
        </BhTabList>
        <BhTabPanels class="tab-panels">
            <BhTabPanel class="tab-panel"><p>First panel</p></BhTabPanel>
            <BhTabPanel class="tab-panel"><p>Second panel</p></BhTabPanel>
            <BhTabPanel class="tab-panel"><p>Third panel</p></BhTabPanel>
        </BhTabPanels>
    </BhTabGroup>
</div>

@code {
    private int selectedIndex;
