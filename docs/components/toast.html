Toast

Short, non-blocking notifications — queued from anywhere, announced to screen readers, dismissed automatically.

Simple toast

Inject BhToaster (registered by AddBlazorHeadless()) and call Show. Toasts appear in a BhToastViewport — a role="region" landmark labelled "Notifications (F8)"; press F8 to jump to it. Every toast is announced through the shared live region, auto-dismisses after the viewport's Duration (paused while hovered or focused) and closes with Escape or a BhToastClose.

Example

Razor

@inject BhToaster Toaster

<BhButton OnClick="ShowSimple" class="btn">Show toast</BhButton>

@* Place ONE viewport in your layout (e.g. MainLayout.razor). *@
<BhToastViewport Context="t" Duration="5000" class="toast-viewport">
    <BhToast Item="t" data-variant="@(t.Data ?? "info")" class="toast">
        @if (t.Data is "success" or "error")
        {
            <span class="toast-icon" aria-hidden="true">@(t.Data is "error" ? "!" : "✓")</span>
        }
        <div class="toast-body">
            <BhToastTitle class="toast-title">@t.Title</BhToastTitle>
            @if (t.Description is not null)
            {
                <BhToastDescription class="toast-description">@t.Description</BhToastDescription>
            }
        </div>
        @if (t.Options.ActionLabel is not null)
        {
            <BhToastAction class="toast-action" />  @* shows ActionLabel *@
        }
        <BhToastClose aria-label="Dismiss notification" class="toast-close">×</BhToastClose>
    </BhToast>
</BhToastViewport>

@code {
    private void ShowSimple() => Toaster.Show("Event created");
}

With an action

Set ActionLabel and OnAction; BhToastAction renders the button, runs the callback and dismisses the toast. Toasts disappear, so keep the action reachable elsewhere too — here "Restore all" stays on the page.

Example

Razor

<ul class="toast-inbox">
    @foreach (var message in inbox)
    {
        <li class="toast-inbox-item" @key="message">
            <span>@message</span>
            <BhButton OnClick="() => Archive(message)" class="btn">Archive</BhButton>
        </li>
    }
</ul>

@code {
    private readonly List<string> inbox = new() { "Quarterly report", "Team offsite plan", "Invoice #1042" };

    private void Archive(string message)
    {
        var index = inbox.IndexOf(message);
        inbox.RemoveAt(index);

        Toaster.Show(new BhToastOptions
        {
            Title = "Conversation archived",
            Description = message,
            ActionLabel = "Undo",                 // rendered by <BhToastAction />
            OnAction = () =>
            {
                inbox.Insert(Math.Min(index, inbox.Count), message);
                return InvokeAsync(StateHasChanged); // runs from the toast, so re-render this page
            },
        });
    }
}

Foreground (assertive) error

Toasts are background (role="status", announced politely) by default. Set Foreground = true for the direct result of a user action that needs attention: it is announced assertively and the toast gets data-type="foreground".

Example

Razor

<BhButton OnClick="ShowError" class="btn">Pay $49.00</BhButton>

@code {
    private void ShowError() => Toaster.Show(new BhToastOptions
    {
        Title = "Payment failed",
        Description = "Your card was declined. Try another payment method.",
        Foreground = true,   // role="alert", announced assertively, data-type="foreground"
        Data = "error",
    });
}

CSS

/* Builds on the base .toast styles from the "Simple toast" demo.
   data-variant comes from BhToastOptions.Data via the template;
   you could also key off [data-type="foreground"]. */
.toast[data-variant="error"] {
    background: #fef2f2;
    border-color: #fecaca;
}
.toast[data-variant="error"] .toast-title { color: #991b1b; }
.toast[data-variant="error"] .toast-icon  { background: #dc2626; }

Razor + Tailwind

<BhButton OnClick="ShowError" class="rounded-lg border border-zinc-200 bg-white px-3 py-1.5 text-sm font-medium hover:bg-zinc-100">
    Pay $49.00
</BhButton>

@code {
    private void ShowError() => Toaster.Show(new BhToastOptions
    {
        Title = "Payment failed",
        Description = "Your card was declined. Try another payment method.",
        Foreground = true,   // role="alert", announced assertively, data-type="foreground"
        Data = "error",      // styled with data-[variant=error]: in the template
    });
}

Custom duration and persistent toasts

Duration (ms) on a toast overrides the viewport's default (5000 ms). Duration = 0 keeps the toast until it is dismissed. Clear() dismisses every toast.

Example

Razor

<BhButton OnClick="() => ShowTimed(2000)" class="btn">2 seconds</BhButton>
<BhButton OnClick="() => ShowTimed(10000)" class="btn">10 seconds</BhButton>
<BhButton OnClick="ShowPersistent" class="btn">Persistent</BhButton>
<BhButton OnClick="() => Toaster.Clear()" class="btn btn-link">Dismiss all</BhButton>

@code {
    private void ShowTimed(int milliseconds) => Toaster.Show(new BhToastOptions
    {
        Title = $"Closes in {milliseconds / 1000} seconds",
        Description = "Hover or focus it to pause the timer.",
        Duration = milliseconds,            // overrides <BhToastViewport Duration="5000">
    });

    private void ShowPersistent() => Toaster.Show(new BhToastOptions
    {
        Title = "Update available",
        Description = "This toast stays until you dismiss it.",
        Duration = 0,                       // 0 or less: never auto-dismiss
    });
}

Stacking with Limit

BhToaster.Limit (default 5) caps how many toasts are kept — the oldest is dropped when a new one arrives. This demo creates its own toaster with Limit = 3 and renders it in a second viewport (passed through Toaster, bottom-left, Shift+F8) styled as a stack that fans out on hover or keyboard focus.

Example

Razor

<BhButton OnClick="AddStacked" class="btn">Add notification</BhButton>

@* A second viewport bound to its own toaster. *@
<BhToastViewport Toaster="stackToaster" Label="Stacked notifications" Hotkey="shift+F8"
                 Context="t" Duration="8000" class="toast-stack">
    <BhToast Item="t" class="toast">
        <div class="toast-body">
            <BhToastTitle class="toast-title">@t.Title</BhToastTitle>
            <BhToastDescription class="toast-description">@t.Description</BhToastDescription>
        </div>
        <BhToastClose aria-label="Dismiss notification" class="toast-close">×</BhToastClose>
    </BhToast>
</BhToastViewport>

@code {
    private readonly BhToaster stackToaster = new() { Limit = 3 };   // oldest dropped beyond 3
    private int stackCount;

    private void AddStacked()
    {
        stackCount++;
        stackToaster.Show(new BhToastOptions
        {
            Title = $"Notification {stackCount}",
            Description = $"Received at {DateTime.Now:HH:mm:ss}.",
        });
    }
}

CSS

/* Builds on the base .toast styles from the "Simple toast" demo.
   Toasts overlap in one grid cell; older ones peek out behind the newest,
   and the stack fans out on hover or keyboard focus. */
.toast-stack {
    position: fixed;
    left: 1rem;
    bottom: 1rem;
    z-index: 100;
    display: grid;
    width: min(20rem, calc(100vw - 2rem));
    margin: 0;
    padding: 0;
    list-style: none;
    outline: none;
}

.toast-stack > .toast {
    grid-area: 1 / 1;
    align-self: end;
    transform-origin: bottom center;
    transition: transform 200ms ease, opacity 200ms ease;
}

.toast-stack > .toast:nth-last-child(2) { transform: translateY(-0.7rem) scale(0.95); opacity: 0.85; }
.toast-stack > .toast:nth-last-child(3) { transform: translateY(-1.4rem) scale(0.9); opacity: 0.7; }

.toast-stack:hover,
.toast-stack:focus-within { display: flex; flex-direction: column; gap: 0.5rem; }

.toast-stack:hover > .toast,
.toast-stack:focus-within > .toast { transform: none; opacity: 1; }

@code {
    private readonly BhToaster stackToaster = new() { Limit = 3 };   // oldest dropped beyond 3
    private int stackCount;

    private void AddStacked()
    {
        stackCount++;
        stackToaster.Show(new BhToastOptions
        {
            Title = $"Notification {stackCount}",
            Description = $"Received at {DateTime.Now:HH:mm:ss}.",
        });
    }

    // 0 = newest (front of the stack)
    private int StackDepth(BhToastItem toast)
    {
        var toasts = stackToaster.Toasts;
        for (var i = 0; i < toasts.Count; i++)
            if (ReferenceEquals(toasts[i], toast)) return toasts.Count - 1 - i;
        return 0;
    }

    private static string StackClass(int depth) => depth switch
    {
        0 => "",
        1 => "-translate-y-3 scale-95 opacity-90 group-hover/stack:translate-y-0 group-hover/stack:scale-100 group-hover/stack:opacity-100 group-focus-within/stack:translate-y-0 ...",
        _ => "-translate-y-6 scale-90 opacity-75 group-hover/stack:translate-y-0 group-hover/stack:scale-100 group-hover/stack:opacity-100 group-focus-within/stack:translate-y-0 ...",
    };
}
