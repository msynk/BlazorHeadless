Transition

CSS class-based enter/leave animations with automatic lifecycle management.

Fade

Toggle the panel. On enter: opacity-0 → opacity-100. On leave: opacity-100 → opacity-0. The element is unmounted after the leave animation completes.

Example

Razor

<BhTransition Show="@isOpen"
             Enter="transition-opacity duration-300"
             EnterFrom="opacity-0"
             EnterTo="opacity-100"
             Leave="transition-opacity duration-200"
             LeaveFrom="opacity-100"
             LeaveTo="opacity-0">
    <div class="panel">I fade in and out.</div>
</BhTransition>

CSS

/* Utility classes — you can use Tailwind or write your own */
.transition-opacity { transition-property: opacity; }
.duration-300       { transition-duration: 300ms; }
.duration-200       { transition-duration: 200ms; }
.opacity-0          { opacity: 0; }
.opacity-100        { opacity: 1; }

Razor + Tailwind

<div class="flex flex-col gap-4 items-start">
    <BhButton OnClick="() => showFade = !showFade"
              class="inline-flex items-center gap-2 rounded-lg border border-blue-600 bg-blue-600 px-4 py-2 text-sm font-medium text-white cursor-pointer hover:bg-blue-700">
        @(showFade ? "Hide" : "Show")
    </BhButton>
    <BhTransition Show="showFade"
                  Enter="transition-opacity duration-300"
                  EnterFrom="opacity-0"
                  EnterTo="opacity-100"
                  Leave="transition-opacity duration-200"
                  LeaveFrom="opacity-100"
                  LeaveTo="opacity-0"
                  class="rounded-lg border border-zinc-200 bg-white p-4 text-sm text-zinc-900 inline-block">
        <p>I fade in and out.</p>
    </BhTransition>
</div>

@code {
    private bool showFade;
}

Scale + Fade

Combine opacity and transform for a more dynamic entrance. The Enter / Leave classes set the transition properties and duration; From / To set the start and end states.

Example

Razor

<BhTransition Show="@isOpen"
             Enter="transition-all duration-300 ease-out"
             EnterFrom="opacity-0 scale-95"
             EnterTo="opacity-100 scale-100"
             Leave="transition-all duration-200 ease-in"
             LeaveFrom="opacity-100 scale-100"
             LeaveTo="opacity-0 scale-95">
    <div class="panel">I scale and fade.</div>
</BhTransition>

CSS

.transition-all { transition-property: all; }
.ease-out       { transition-timing-function: ease-out; }
.ease-in        { transition-timing-function: ease-in; }
.scale-95       { transform: scale(0.95); }
.scale-100      { transform: scale(1); }

Razor + Tailwind

<div class="flex flex-col gap-4 items-start">
    <BhButton OnClick="() => showScale = !showScale"
              class="inline-flex items-center gap-2 rounded-lg border border-blue-600 bg-blue-600 px-4 py-2 text-sm font-medium text-white cursor-pointer hover:bg-blue-700">
        @(showScale ? "Hide" : "Show")
    </BhButton>
    <BhTransition Show="showScale"
                  Enter="transition-all duration-300 ease-out"
                  EnterFrom="opacity-0 scale-95"
                  EnterTo="opacity-100 scale-100"
                  Leave="transition-all duration-200 ease-in"
                  LeaveFrom="opacity-100 scale-100"
                  LeaveTo="opacity-0 scale-95"
                  class="rounded-lg border border-zinc-200 bg-white p-4 text-sm text-zinc-900 inline-block">
        <p>I scale and fade.</p>
    </BhTransition>
</div>

@code {
    private bool showScale;
}

Slide Down

A slide-down reveal using max-height and overflow: hidden. Useful for accordion-style content reveals.

Example

Razor

<BhTransition Show="@isOpen"
             Enter="slide-enter"
             EnterFrom="slide-enter-from"
             EnterTo="slide-enter-to"
             Leave="slide-leave"
             LeaveFrom="slide-leave-from"
             LeaveTo="slide-leave-to">
    <div class="panel">I slide down.</div>
</BhTransition>

CSS

/* Slide-down using max-height */
.slide-box          { overflow: hidden; }
.slide-enter        { transition: max-height 300ms ease-out, opacity 300ms ease-out; }
.slide-enter-from   { max-height: 0; opacity: 0; }
.slide-enter-to     { max-height: 10rem; opacity: 1; }
.slide-leave        { transition: max-height 200ms ease-in, opacity 200ms ease-in; }
.slide-leave-from   { max-height: 10rem; opacity: 1; }
.slide-leave-to     { max-height: 0; opacity: 0; }

With Appear

Set Appear="true" to run the enter transition on initial mount. Without it, elements that start with Show="true" appear instantly.

Example

Razor

<BhTransition Show="@isOpen"
             Appear="true"
             Enter="transition-all duration-500 ease-out"
             EnterFrom="opacity-0 translate-y-4"
             EnterTo="opacity-100 translate-y-0"
             Leave="transition-all duration-300 ease-in"
             LeaveFrom="opacity-100 translate-y-0"
             LeaveTo="opacity-0 translate-y-4">
    <div class="panel">I animate on first mount too.</div>
</BhTransition>

@* Without Appear="true", elements that start with Show="true" appear instantly. *@

CSS

.translate-y-4  { transform: translateY(1rem); }
.translate-y-0  { transform: translateY(0); }
.duration-500   { transition-duration: 500ms; }

Razor + Tailwind

<div class="flex flex-col gap-4 items-start">
    <BhButton OnClick="() => showAppear = !showAppear"
              class="inline-flex items-center gap-2 rounded-lg border border-blue-600 bg-blue-600 px-4 py-2 text-sm font-medium text-white cursor-pointer hover:bg-blue-700">
        @(showAppear ? "Hide" : "Show")
    </BhButton>
    <BhTransition Show="showAppear" Appear="true"
                  Enter="transition-all duration-500 ease-out"
                  EnterFrom="opacity-0 translate-y-4"
                  EnterTo="opacity-100 translate-y-0"
                  Leave="transition-all duration-300 ease-in"
                  LeaveFrom="opacity-100 translate-y-0"
                  LeaveTo="opacity-0 translate-y-4"
                  class="rounded-lg border border-zinc-200 bg-white p-4 text-sm text-zinc-900 inline-block">
        <p>I animate on first mount too.</p>
    </BhTransition>
</div>

@code {
    private bool showAppear = true;
}

Lifecycle Callbacks

Use BeforeEnter, AfterEnter, BeforeLeave, AfterLeave to run logic at each phase of the transition.

Example

Razor

<BhTransition Show="@isOpen"
             Enter="transition-opacity duration-300"
             EnterFrom="opacity-0"
             EnterTo="opacity-100"
             Leave="transition-opacity duration-200"
             LeaveFrom="opacity-100"
             LeaveTo="opacity-0"
             BeforeEnter="() => Log(\"BeforeEnter\")"
             AfterEnter="() => Log(\"AfterEnter\")"
             BeforeLeave="() => Log(\"BeforeLeave\")"
             AfterLeave="() => Log(\"AfterLeave\")">
    <div class="panel">Check the log.</div>
</BhTransition>

CSS

/* Same fade classes as the first demo — no extra CSS needed for callbacks. */

Razor + Tailwind

<div class="flex flex-col gap-4 items-start">
    <BhButton OnClick="() => showCallbacks = !showCallbacks"
              class="inline-flex items-center gap-2 rounded-lg border border-blue-600 bg-blue-600 px-4 py-2 text-sm font-medium text-white cursor-pointer hover:bg-blue-700">
        @(showCallbacks ? "Hide" : "Show")
    </BhButton>
    <BhTransition Show="showCallbacks"
                  Enter="transition-opacity duration-300" EnterFrom="opacity-0" EnterTo="opacity-100"
                  Leave="transition-opacity duration-200" LeaveFrom="opacity-100" LeaveTo="opacity-0"
                  BeforeEnter='@(() => Log("BeforeEnter"))'
                  AfterEnter='@(() => Log("AfterEnter"))'
                  BeforeLeave='@(() => Log("BeforeLeave"))'
                  AfterLeave='@(() => Log("AfterLeave"))'
                  class="rounded-lg border border-zinc-200 bg-white p-4 text-sm text-zinc-900 inline-block">
        <p>Check the log below.</p>
    </BhTransition>
    <pre class="text-xs text-zinc-500 whitespace-pre-wrap">@callbackLog</pre>
</div>

@code {
    private bool showCallbacks;
    private string callbackLog = "";

    private void Log(string msg) => callbackLog += msg + "\n";
}
