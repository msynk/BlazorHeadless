Disclosure

A single show/hide region toggled by a button — the simplest collapsible primitive.

Basic Disclosure

Renders a button and a panel. Clicking the button toggles the panel. aria-expanded, aria-controls, and aria-labelledby are wired automatically.

Example

Razor

<BhDisclosure class="disclosure">
    <BhDisclosureButton class="disclosure-button">
        Show details
    </BhDisclosureButton>
    <BhDisclosurePanel class="disclosure-panel">
        <div class="disclosure-body">
            Disclosure is the simpler sibling of Accordion: one trigger, one panel,
            zero coordination across siblings.
        </div>
    </BhDisclosurePanel>
</BhDisclosure>

CSS

/* All styles are consumer-authored — the library ships zero CSS */
.disclosure {
    width: 100%;
    border: 1px solid #e4e4e7;
    border-radius: 0.5rem;
    overflow: hidden;
    background: #fff;
}

.disclosure-button {
    all: unset;
    display: flex;
    align-items: center;
    justify-content: space-between;
    width: 100%;
    padding: 0.875rem 1.125rem;
    font-weight: 500;
    cursor: pointer;
    box-sizing: border-box;
}

.disclosure-button:hover                { background: #f4f4f5; }
.disclosure-button:focus-visible        { outline: 2px solid #2563eb; outline-offset: -2px; }
.disclosure-button[data-state="open"]   { background: #f4f4f5; }
.disclosure-button[data-disabled]       { opacity: 0.5; cursor: not-allowed; pointer-events: none; }

.disclosure-body {
    padding: 0.875rem 1.125rem 1rem;
    color: #71717a;
    border-top: 1px solid #e4e4e7;
}

Default Open

Set DefaultOpen="true" to render the panel open initially (uncontrolled).

Example

Razor

<BhDisclosure DefaultOpen="true" class="disclosure">
    <BhDisclosureButton class="disclosure-button">
        Already open
    </BhDisclosureButton>
    <BhDisclosurePanel class="disclosure-panel">
        <div class="disclosure-body">
            I'm open by default. Click the button to close me.
        </div>
    </BhDisclosurePanel>
</BhDisclosure>

CSS

/* Reuses the .disclosure / .disclosure-button styles from the Basic demo.
   When DefaultOpen="true" the button is rendered with data-state="open" on
   first paint so the open-state styles apply immediately. */
.disclosure-button[data-state="open"] { background: #f4f4f5; }

Render Context (rotating chevron + Close)

BhDisclosure, BhDisclosureButton, and BhDisclosurePanel all expose a BhDisclosureRenderContext via Context="d". Use it to drive UI from the open state and to call d.Close() from anywhere inside.

Example

Razor

<BhDisclosure class="disclosure">
    <BhDisclosureButton class="disclosure-button" Context="d">
        <span>What's inside?</span>
        <span class="disclosure-chevron @(d.IsOpen ? "open" : "")">▾</span>
    </BhDisclosureButton>
    <BhDisclosurePanel class="disclosure-panel" Context="d">
        <div class="disclosure-body">
            <p>You can close me from inside the panel:</p>
            <button class="btn" @onclick="d.Close">Close panel</button>
        </div>
    </BhDisclosurePanel>
</BhDisclosure>

CSS

/* Rotating chevron driven by BhDisclosureRenderContext.IsOpen */
.disclosure-chevron      { transition: transform 200ms ease; color: #71717a; }
.disclosure-chevron.open { transform: rotate(180deg); }

Razor + Tailwind

<BhDisclosure class="w-full overflow-hidden rounded-lg border border-zinc-200 bg-white data-disabled:bg-zinc-50">
    <BhDisclosureButton class="flex w-full cursor-pointer items-center justify-between border-0 bg-transparent px-5 py-3.5 text-base font-medium outline-none hover:bg-zinc-100 focus-visible:outline-2 focus-visible:outline-offset-[-2px] focus-visible:outline-blue-600 data-state-open:bg-zinc-100 data-disabled:opacity-50 data-disabled:cursor-not-allowed data-disabled:pointer-events-none"
                        Context="d">
        <span>What's inside?</span>
        <span class="@($"text-zinc-500 transition-transform duration-200 {(d.IsOpen ? "rotate-180" : "")}")">▾</span>
    </BhDisclosureButton>
    <BhDisclosurePanel Context="d">
        <div class="border-t border-zinc-200 px-5 py-3.5 text-sm text-zinc-500">
            <p>You can close me from inside the panel:</p>
            <button class="mt-3 rounded-lg border border-zinc-200 bg-white px-3 py-1.5 text-sm font-medium hover:bg-zinc-100" @onclick="d.Close">Close panel</button>
        </div>
    </BhDisclosurePanel>
</BhDisclosure>

Disabled

Set Disabled="true" on the root to block interaction. The button receives both the native disabled attribute and a data-disabled hook.

Example

Razor

<BhDisclosure Disabled="true" class="disclosure">
    <BhDisclosureButton class="disclosure-button">Can't toggle me</BhDisclosureButton>
    <BhDisclosurePanel class="disclosure-panel">
        <div class="disclosure-body">You'll never see this content.</div>
    </BhDisclosurePanel>
</BhDisclosure>

CSS

/* Hooks emitted when Disabled="true" */
.disclosure-button[data-disabled] {
    opacity: 0.5;
    cursor: not-allowed;
    pointer-events: none;
}

/* The root <BhDisclosure> element also receives data-disabled — useful for
   dimming the entire region. */
.disclosure[data-disabled] {
    background: #fafafa;
}

<BhDisclosure Disabled="true" class="w-full overflow-hidden rounded-lg border border-zinc-200 bg-white data-disabled:bg-zinc-50">

Controlled

Drive the open state externally with Open + OnOpenChange. The button below opens or closes the disclosure programmatically.

Example

Razor

<div style="display:flex; flex-direction:column; gap:1rem; width:100%">
    <div class="demo-row">
        <BhButton OnClick="ToggleControlled" class="btn">
            Toggle from outside
        </BhButton>
        <span class="demo-output">Open: @controlledOpen.ToString().ToLowerInvariant()</span>
    </div>

    <BhDisclosure Open="controlledOpen"
                 OnOpenChange="v => controlledOpen = v"
                 class="disclosure">
        <BhDisclosureButton class="disclosure-button">
            Internal trigger
        </BhDisclosureButton>
        <BhDisclosurePanel class="disclosure-panel">
            <div class="disclosure-body">
                Either trigger updates the same state — fully controlled.
            </div>
        </BhDisclosurePanel>
    </BhDisclosure>
</div>

@code {
    private bool controlledOpen;

    private void ToggleControlled() => controlledOpen = !controlledOpen;
}

CSS

/* Reuses the .disclosure / .disclosure-button styles from the Basic demo.
   Controlled mode adds no special CSS hooks — data-state simply reflects
   whatever Open value you bind to. */

Razor + Tailwind

            Internal trigger
        </BhDisclosureButton>
        <BhDisclosurePanel>
