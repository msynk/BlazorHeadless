CloseButton

A utility button pre-wired to close the nearest enclosing Dialog, Popover, or Disclosure — saves boilerplate for dismiss actions.

Inside a Dialog

Drop <BhCloseButton> anywhere inside a Dialog and it will automatically call the dialog's close callback. No need to wire up @@onclick or pass state around.

Example

Razor

<BhButton OnClick="() => isOpen = true" class="btn btn-primary">
    Open dialog
</BhButton>

<BhDialog Open="isOpen" OnClose="() => isOpen = false">
    <BhDialogBackdrop class="dialog-backdrop" />
    <BhDialogPanel class="dialog-panel">
        <BhDialogTitle>Deactivate account</BhDialogTitle>
        <BhDialogDescription>
            This will permanently deactivate your account.
        </BhDialogDescription>

        <div class="dialog-actions">
            <!-- No @onclick needed — BhCloseButton finds the Dialog automatically -->
            <BhCloseButton class="btn">Cancel</BhCloseButton>
            <BhCloseButton class="btn btn-danger">Deactivate</BhCloseButton>
        </div>
    </BhDialogPanel>
</BhDialog>

@code {
    private bool isOpen;
}

CSS

.dialog-backdrop { background: rgba(0, 0, 0, 0.5); }

.dialog-panel {
    margin: 4rem auto;
    max-width: 28rem;
    background: #fff;
    border-radius: 0.75rem;
    box-shadow: 0 25px 50px -12px rgba(0, 0, 0, 0.25);
    padding: 1.5rem;
    display: flex;
    flex-direction: column;
    gap: 0.85rem;
}

.dialog-title       { font-size: 1.1rem; font-weight: 600; color: #18181b; }
.dialog-description { font-size: 0.9rem; color: #71717a; }
.dialog-actions     { display: flex; justify-content: flex-end; gap: 0.5rem; margin-top: 0.5rem; }

.btn-danger {
    background: #dc2626;
    border-color: #dc2626;
    color: #fff;
}

Razor + Tailwind

<BhButton OnClick="() => dialogOpen = true"
          class="inline-flex items-center gap-2 rounded-lg border border-blue-600 bg-blue-600 px-4 py-2 text-sm font-medium text-white cursor-pointer hover:bg-blue-700">
    Open dialog
</BhButton>
<BhDialog Open="dialogOpen" OnClose="() => dialogOpen = false">
    <BhDialogBackdrop class="bg-black/50" />
    <BhDialogPanel class="mx-auto my-16 max-w-md rounded-xl bg-white p-6 shadow-2xl flex flex-col gap-3">
        <BhDialogTitle class="text-lg font-semibold text-zinc-900">Deactivate account</BhDialogTitle>
        <BhDialogDescription class="text-sm text-zinc-500">
            This will permanently deactivate your account. All of your data will be permanently removed.
        </BhDialogDescription>

            <BhCloseButton class="inline-flex items-center gap-2 rounded-lg border border-zinc-200 bg-white px-4 py-2 text-sm font-medium text-zinc-900 cursor-pointer hover:bg-zinc-100">Cancel</BhCloseButton>
            <BhCloseButton class="inline-flex items-center gap-2 rounded-lg border border-red-600 bg-red-600 px-4 py-2 text-sm font-medium text-white cursor-pointer hover:bg-red-700">Deactivate</BhCloseButton>
        </div>
    </BhDialogPanel>
</BhDialog>

@code {
    private bool dialogOpen;
}

Inside a Popover

Use BhCloseButton inside a popover panel to close it on click. Combine with the As parameter to render as an anchor or any other element.

Example

Razor

<BhPopover class="popover">
    <BhPopoverButton class="popover-button">Solutions ▾</BhPopoverButton>
    <BhPopoverPanel class="popover-panel">
        <h3 class="popover-title">Navigation</h3>

        <!-- Render as <a> elements that also close the popover on click -->
        <BhCloseButton As="a" href="#analytics" class="popover-nav-link">
            Analytics
        </BhCloseButton>
        <BhCloseButton As="a" href="#engagement" class="popover-nav-link">
            Engagement
        </BhCloseButton>

        <hr class="popover-divider" />
        <BhCloseButton class="popover-dismiss">Dismiss ✕</BhCloseButton>
    </BhPopoverPanel>
</BhPopover>

CSS

.popover { position: relative; display: inline-block; }

.popover-button {
    display: inline-flex;
    align-items: center;
    gap: 0.4rem;
    padding: 0.5rem 0.9rem;
    border: 1px solid #d4d4d8;
    border-radius: 0.5rem;
    background: #fff;
    font-size: 0.9rem;
    cursor: pointer;
}

.popover-panel {
    position: absolute;
    top: calc(100% + 0.5rem);
    left: 0;
    z-index: 31;
    min-width: 14rem;
    background: #fff;
    border: 1px solid #e4e4e7;
    border-radius: 0.5rem;
    box-shadow: 0 8px 24px rgba(0, 0, 0, 0.1);
    padding: 0.75rem;
    display: flex;
    flex-direction: column;
    gap: 0.4rem;
}

.popover-title      { font-size: 0.9rem; font-weight: 600; margin: 0; }
.popover-nav-link   { font-size: 0.85rem; color: #2563eb; text-decoration: none; padding: 0.3rem 0; }
.popover-nav-link:hover { text-decoration: underline; }
.popover-divider    { border: none; border-top: 1px solid #e4e4e7; margin: 0.25rem 0; }

.popover-dismiss {
    all: unset;
    display: block;
    width: 100%;
    font-size: 0.8rem;
    font-family: inherit;
    color: #71717a;
    cursor: pointer;
    text-align: center;
    padding: 0.4rem;
    border-radius: 0.35rem;
    box-sizing: border-box;
}
.popover-dismiss:hover { color: #18181b; background: #f4f4f5; }
.popover-dismiss:focus-visible { outline: 2px solid #2563eb; outline-offset: 2px; }

Inside a Disclosure

Works the same way inside a Disclosure. The button finds the nearest closeable ancestor and calls its close method.

Example

Razor

<BhDisclosure DefaultOpen="true" class="disclosure">
    <BhDisclosureButton class="disclosure-button">
        Show details
    </BhDisclosureButton>
    <BhDisclosurePanel class="disclosure-panel">
        <div class="disclosure-body">
            <p>Here are some details you can collapse.</p>
            <BhCloseButton class="btn btn-sm">Hide details</BhCloseButton>
        </div>
    </BhDisclosurePanel>
</BhDisclosure>

CSS

.disclosure {
    width: 100%;
    border: 1px solid #e4e4e7;
    border-radius: 0.5rem;
    overflow: hidden;
    background: #fff;
}

.disclosure-button {
    all: unset;
    display: flex;
    align-items: center;
    justify-content: space-between;
    width: 100%;
    padding: 0.875rem 1.125rem;
    font-weight: 500;
    cursor: pointer;
    box-sizing: border-box;
}

.disclosure-button:hover              { background: #f4f4f5; }
.disclosure-button[data-state="open"] { background: #f4f4f5; }

.disclosure-body {
    padding: 0.875rem 1.125rem 1rem;
    color: #71717a;
    border-top: 1px solid #e4e4e7;
    display: flex;
    flex-direction: column;
    gap: 0.75rem;
}

.btn-sm { font-size: 0.8rem; padding: 0.35rem 0.7rem; }

Razor + Tailwind

<BhDisclosure DefaultOpen="true" class="w-full overflow-hidden rounded-lg border border-zinc-200 bg-white">
    <BhDisclosureButton class="flex w-full cursor-pointer items-center justify-between border-0 bg-transparent px-5 py-3.5 font-medium hover:bg-zinc-100 data-state-open:bg-zinc-100">
        Show details
    </BhDisclosureButton>
    <BhDisclosurePanel>
        <div class="border-t border-zinc-200 px-5 py-3.5 flex flex-col gap-3 text-sm text-zinc-500">
            <p>Here are some details you can collapse.</p>
            <BhCloseButton class="inline-flex items-center gap-2 rounded-lg border border-zinc-200 bg-white text-xs font-medium text-zinc-900 px-3 py-1.5 cursor-pointer hover:bg-zinc-100 self-start">Hide details</BhCloseButton>
        </div>
    </BhDisclosurePanel>
</BhDisclosure>

Polymorphic rendering (As)

Use the As parameter to render the close button as any HTML element. Non-native button elements automatically receive role="button", tabindex="0", and Enter/Space keyboard handling.

Example

Razor

<BhPopover class="popover">
    <BhPopoverButton class="popover-button">Open panel ▾</BhPopoverButton>
    <BhPopoverPanel class="popover-panel">
        <!-- Default: renders as <button> -->
        <BhCloseButton class="btn btn-sm">Button (default)</BhCloseButton>

        <!-- Renders as <a> with role="button" and keyboard handling -->
        <BhCloseButton As="a" href="#" class="popover-nav-link">
            Anchor link
        </BhCloseButton>

        <!-- Renders as <div> with role="button", tabindex, keyboard -->
        <BhCloseButton As="div" class="close-div">
            Div with role="button"
        </BhCloseButton>
    </BhPopoverPanel>
</BhPopover>

CSS

/* Reuses .popover styles from above */

.close-variants {
    display: flex;
    flex-direction: column;
    gap: 0.5rem;
    margin-top: 0.5rem;
}

.close-div {
    padding: 0.4rem 0.7rem;
    background: #f4f4f5;
    border-radius: 0.4rem;
    font-size: 0.85rem;
    cursor: pointer;
    text-align: center;
}

.close-div:hover        { background: #e4e4e7; }
.close-div:focus-visible { outline: 2px solid #2563eb; outline-offset: 2px; }

Razor + Tailwind

<BhPopover class="relative inline-block">
    <BhPopoverButton class="inline-flex items-center gap-2 rounded-lg border border-zinc-300 bg-white px-3.5 py-2 text-sm cursor-pointer hover:border-zinc-400 data-state-open:border-blue-600">
        Open panel ▾
    </BhPopoverButton>
    <BhPopoverPanel class="absolute top-[calc(100%+0.5rem)] left-0 z-30 min-w-56 rounded-lg border border-zinc-200 bg-white p-3 shadow-lg flex flex-col gap-1.5">
        <p class="text-sm text-zinc-500 m-0">The close actions below render as different elements:</p>
        <div class="mt-2 flex flex-col gap-2">
            <BhCloseButton class="inline-flex items-center gap-2 rounded-lg border border-zinc-200 bg-white text-xs font-medium text-zinc-900 px-3 py-1.5 cursor-pointer hover:bg-zinc-100">Button (default)</BhCloseButton>
            <BhCloseButton As="a" href="#" class="py-1 text-sm text-blue-600 no-underline hover:underline">Anchor link</BhCloseButton>
            <BhCloseButton As="div" class="rounded-md bg-zinc-100 px-2.5 py-1.5 text-center text-sm cursor-pointer hover:bg-zinc-200 focus-visible:outline-2 focus-visible:outline-offset-2 focus-visible:outline-blue-600">Div with role="button"</BhCloseButton>
        </div>
    </BhPopoverPanel>
</BhPopover>

Disabled state

Set Disabled="true" to prevent the close action. The button receives the native disabled attribute (or aria-disabled for non-native elements) and a data-disabled styling hook.

Example

Razor

<BhPopover class="popover">
    <BhPopoverButton class="popover-button">Panel is open ▾</BhPopoverButton>
    <BhPopoverPanel class="popover-panel">
        <p>The disabled close button won't close this panel:</p>

        <BhCloseButton Disabled="true" class="btn btn-sm">
            Can't close (disabled)
        </BhCloseButton>
        <BhCloseButton class="btn btn-sm btn-primary">
            Close (enabled)
        </BhCloseButton>
    </BhPopoverPanel>
</BhPopover>

CSS

/* Reuses .popover styles from above */

/* Style the disabled state via the data-disabled attribute */
[data-disabled] {
    opacity: 0.5;
    cursor: not-allowed;
}

Razor + Tailwind

<BhPopover class="relative inline-block">
    <BhPopoverButton class="inline-flex items-center gap-2 rounded-lg border border-zinc-300 bg-white px-3.5 py-2 text-sm cursor-pointer hover:border-zinc-400 data-state-open:border-blue-600">
        Panel is open ▾
    </BhPopoverButton>
    <BhPopoverPanel class="absolute top-[calc(100%+0.5rem)] left-0 z-30 min-w-56 rounded-lg border border-zinc-200 bg-white p-3 shadow-lg flex flex-col gap-1.5">
        <p class="text-sm text-zinc-500 m-0">The disabled close button below won't close this panel:</p>
        <div class="mt-2 flex flex-col gap-2">
            <BhCloseButton Disabled="true"
                           class="inline-flex items-center gap-2 rounded-lg border border-zinc-200 bg-white text-xs font-medium text-zinc-900 px-3 py-1.5 cursor-pointer hover:bg-zinc-100 data-disabled:opacity-50 data-disabled:cursor-not-allowed">
                Can't close (disabled)
            </BhCloseButton>
            <BhCloseButton class="inline-flex items-center gap-2 rounded-lg border border-blue-600 bg-blue-600 text-xs font-medium text-white px-3 py-1.5 cursor-pointer hover:bg-blue-700">
                Close (enabled)
            </BhCloseButton>
        </div>
    </BhPopoverPanel>
</BhPopover>
