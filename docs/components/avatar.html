Avatar

An image element with a graceful fallback for representing a user or entity.

Basic

Compose BhAvatarImage with a BhAvatarFallback inside BhAvatar. The image is only shown once it loads successfully — until then the fallback initials are displayed.

Example

Razor

<BhAvatar class="avatar">
    <BhAvatarImage class="avatar-image" Src="/colm.jpg" Alt="Colm Tuite" />
    <BhAvatarFallback class="avatar-fallback">CT</BhAvatarFallback>
</BhAvatar>

CSS

/* The library ships zero CSS — these styles are consumer-authored. */
.avatar {
    display: inline-flex;
    align-items: center;
    justify-content: center;
    vertical-align: middle;
    overflow: hidden;
    user-select: none;
    width: 3rem;
    height: 3rem;
    border-radius: 100%;
    background: #e4e4e7;
}

.avatar-image {
    width: 100%;
    height: 100%;
    object-fit: cover;
    border-radius: inherit;
}

.avatar-fallback {
    display: flex;
    align-items: center;
    justify-content: center;
    width: 100%;
    height: 100%;
    font-size: 0.95rem;
    font-weight: 600;
    color: #3f3f46;
    background: #e4e4e7;
}

Razor + Tailwind

<BhAvatar class="inline-flex h-12 w-12 items-center justify-center overflow-hidden rounded-full bg-zinc-200 align-middle select-none">
    <BhAvatarImage class="h-full w-full rounded-[inherit] object-cover" Src="/colm.jpg" Alt="Colm Tuite" />
    <BhAvatarFallback class="flex h-full w-full items-center justify-center bg-zinc-200 text-sm font-semibold text-zinc-700">CT</BhAvatarFallback>
</BhAvatar>

Fallback (broken image)

When the image fails to load (or no Src is given), the fallback is shown instead of a broken-image icon. Here the source is intentionally invalid.

Example

Razor

@* Broken / missing image → the fallback shows automatically *@
<BhAvatar class="avatar">
    <BhAvatarImage class="avatar-image" Src="/does-not-exist.jpg" Alt="Jane Doe" />
    <BhAvatarFallback class="avatar-fallback">JD</BhAvatarFallback>
</BhAvatar>

@* Fallback with no image at all — e.g. a generic user icon *@
<BhAvatar class="avatar">
    <BhAvatarFallback class="avatar-fallback avatar-fallback-icon">
        <svg viewBox="0 0 24 24" width="22" height="22" ...>...</svg>
    </BhAvatarFallback>
</BhAvatar>

    height: 3rem;
    border-radius: 100%;
    background: #e4e4e7;
}

.avatar-image {
    width: 100%;
    height: 100%;
    object-fit: cover;
    border-radius: inherit;
}

.avatar-fallback {
    display: flex;

Delayed fallback

Set DelayMs on the fallback to wait before showing it. This avoids a flash of initials for images that load quickly. The fallback only appears if the image hasn't loaded by the time the delay elapses.

Example

Razor

<BhAvatar class="avatar">
    <BhAvatarImage class="avatar-image" Src="/pedro.jpg" Alt="Pedro Duarte" />
    <BhAvatarFallback class="avatar-fallback" DelayMs="600">PD</BhAvatarFallback>
</BhAvatar>

    height: 100%;

    border-radius: inherit;
}

    display: flex;
    align-items: center;

Sizes and shapes

The library ships zero styling, so size and shape are entirely up to your CSS. Override class per avatar for circles, squares, or stacked groups.

Example

Razor

<div class="avatar-row">
    <BhAvatar class="avatar avatar-sm">
        <BhAvatarImage class="avatar-image" Src="/a.jpg" Alt="" />
        <BhAvatarFallback class="avatar-fallback">AB</BhAvatarFallback>
    </BhAvatar>

    <BhAvatar class="avatar">
        <BhAvatarImage class="avatar-image" Src="/b.jpg" Alt="" />
        <BhAvatarFallback class="avatar-fallback">CD</BhAvatarFallback>
    </BhAvatar>

    <BhAvatar class="avatar avatar-lg avatar-square">
        <BhAvatarImage class="avatar-image" Src="/c.jpg" Alt="" />
        <BhAvatarFallback class="avatar-fallback">EF</BhAvatarFallback>
    </BhAvatar>
</div>

CSS

/* The library ships zero CSS — these styles are consumer-authored. */
.avatar {
    display: inline-flex;
    align-items: center;
    justify-content: center;
    vertical-align: middle;
    overflow: hidden;
    user-select: none;
    width: 3rem;
    height: 3rem;
    border-radius: 100%;
    background: #e4e4e7;
}

.avatar-image {
    width: 100%;
    height: 100%;
    object-fit: cover;
    border-radius: inherit;
}

.avatar-fallback {
    display: flex;
    align-items: center;
    justify-content: center;
    width: 100%;
    height: 100%;
    font-size: 0.95rem;
    font-weight: 600;
    color: #3f3f46;
    background: #e4e4e7;
}

/* Lay the avatars out in a row; modifiers tweak size and shape */
.avatar-row {
    display: flex;
    align-items: center;
    gap: 1rem;
}

.avatar-sm { width: 2.25rem; height: 2.25rem; font-size: 0.8rem; }
.avatar-lg { width: 4rem;    height: 4rem;    font-size: 1.1rem; }

.avatar-square { border-radius: 0.6rem; }
