Progress / Meter

Report task completion with a progress bar, or a measurement within a known range with a meter.

Determinate progress

BhProgress renders role="progressbar" with aria-valuenow/min/max and a percentage aria-valuetext. It exposes --bh-progress (a unitless 0–100 number) and data-state="loading|complete"; size the BhProgressIndicator with calc(var(--bh-progress) * 1%). Name it with aria-labelledby.

Example

Razor

<div class="progress-card">
    <div class="progress-header">
        <span class="progress-label" id="profile-label">Profile completion</span>
        <span class="progress-status">@profile%</span>
    </div>
    <BhProgress Value="profile" aria-labelledby="profile-label" class="progress">
        <BhProgressIndicator class="progress-indicator" />
    </BhProgress>
    <div class="progress-actions">
        <button type="button" class="progress-btn" @onclick="() => profile = Math.Max(0, profile - 20)">− 20%</button>
        <button type="button" class="progress-btn" @onclick="() => profile = Math.Min(100, profile + 20)">+ 20%</button>
    </div>
</div>

@code {
    private double profile = 60;
}

Simulated upload

A timer drives Value in megabytes against Max="8"; ValueText turns it into "2.4 of 8 MB uploaded" for screen readers. The upload starts with Value="null" (indeterminate) while "preparing". Template receives the computed percentage (double?) to draw the label inside the bar. The page implements IDisposable to stop the timer.

Example

Razor

@implements IDisposable

<div class="progress-card">
    <div class="progress-header">
        <span class="progress-label" id="upload-label">quarterly-report.pdf</span>
        <span class="progress-status">@UploadStatus()</span>
    </div>
    <BhProgress Value="uploaded" Max="FileSizeMb"
                ValueText="@((v, max) => $"{v:0.0} of {max:0} MB uploaded")"
                aria-labelledby="upload-label" class="progress progress-lg">
        <Template Context="percent">
            <BhProgressIndicator class="progress-indicator" />
            <span class="progress-percent">@(percent is null ? "" : $"{percent:0}%")</span>
        </Template>
    </BhProgress>
    <div class="progress-actions">
        <button type="button" class="progress-btn progress-btn-primary"
                disabled="@uploading" @onclick="StartUpload">
            @(uploaded >= FileSizeMb ? "Upload again" : "Start upload")
        </button>
        <button type="button" class="progress-btn"
                disabled="@(!uploading)" @onclick="CancelUpload">Cancel</button>
    </div>
</div>

@code {
    private const double FileSizeMb = 8;
    private double? uploaded = 0;          // null = indeterminate
    private bool uploading;
    private int uploadTicks;
    private System.Threading.Timer? uploadTimer;

    private string UploadStatus()
    {
        if (uploaded is null) return "Preparing…";
        if (uploaded >= FileSizeMb) return "Complete";
        if (!uploading) return "Ready";
        return $"{uploaded:0.0} of {FileSizeMb:0} MB";
    }

    private void StartUpload()
    {
        uploadTimer?.Dispose();
        uploading = true;
        uploaded = null;   // indeterminate while "preparing"
        uploadTicks = 0;
        uploadTimer = new System.Threading.Timer(_ => InvokeAsync(UploadTick), null, 150, 150);
    }

    private void UploadTick()
    {
        if (!uploading) return;
        uploadTicks++;
        if (uploadTicks > 6)   // ~1 s of "preparing" first
        {
            uploaded = Math.Min(FileSizeMb, (uploaded ?? 0) + 0.2);
            if (uploaded >= FileSizeMb) StopTimer();
        }
        StateHasChanged();
    }

    private void CancelUpload()
    {
        StopTimer();
        uploaded = 0;
    }

    private void StopTimer()
    {
        uploading = false;
        uploadTimer?.Dispose();
        uploadTimer = null;
    }

    public void Dispose() => uploadTimer?.Dispose();
}

Meter: disk usage

BhMeter (role="meter") shows a scalar within a known range — not task progress. Low and High split the range into data-level="low|optimum|high", and --bh-meter (0–100) sizes the fill. ValueText gives a readable value.

Example

Razor

<ul class="meter-list">
    @foreach (var drive in drives)
    {
        <li class="meter-row">
            <div class="progress-header">
                <span class="progress-label" id="@($"drive-{drive.Id}")">@drive.Name</span>
                <span class="progress-status">@drive.Used of 256 GB</span>
            </div>
            <BhMeter Value="drive.Used" Max="256" Low="64" High="200"
                     ValueText="@(v => $"{v} of 256 GB used")"
                     aria-labelledby="@($"drive-{drive.Id}")" class="meter">
                <span class="meter-fill"></span>
            </BhMeter>
        </li>
    }
</ul>

@code {
    private readonly (string Id, string Name, double Used)[] drives =
        [("system", "System", 231), ("projects", "Projects", 118), ("backup", "Backup", 37)];

Meter: password strength

A 0–4 score with Low="2" and High="3": weak scores are low, fair ones optimum, a full score high. BhMeter's Template receives the percentage, used here to fill four segments.

Example

Razor

<div class="strength">
    <label for="pw" class="progress-label">Choose a password</label>
    <input id="pw" type="password" class="strength-input" autocomplete="new-password"
           @bind="password" @bind:event="oninput" aria-describedby="pw-strength" />
    <BhMeter Value="Score()" Max="4" Low="2" High="3"
             ValueText="@(v => StrengthLabels[(int)v])"
             aria-label="Password strength" class="strength-meter">
        <Template Context="percent">
            @for (var i = 1; i <= 4; i++)
            {
                <span class="strength-segment" data-filled="@(percent >= i * 25)"></span>
            }
        </Template>
    </BhMeter>
    <span class="progress-status" id="pw-strength">Strength: <strong>@(StrengthLabels[Score()])</strong></span>
</div>

@code {
    private string password = "";
    private static readonly string[] StrengthLabels = ["Very weak", "Weak", "Fair", "Good", "Strong"];

    private int Score()
    {
        if (password.Length == 0) return 0;
        var score = 0;
        if (password.Length >= 8) score++;
        if (password.Any(char.IsUpper) && password.Any(char.IsLower)) score++;
        if (password.Any(char.IsDigit)) score++;
        if (password.Any(c => !char.IsLetterOrDigit(c))) score++;
        return score;
    }
}

           @bind="password" @bind:event="oninput" aria-describedby="tw-pw-strength"
           class="rounded-md border border-zinc-300 bg-white px-3 py-2 text-sm outline-none focus-visible:ring-2 focus-visible:ring-blue-600" />
    <BhMeter Value="Score()" Max="4" Low="2" High="3"
             ValueText="@(v => StrengthLabels[(int)v])"
             aria-label="Password strength"
             class="group grid grid-cols-4 gap-1">
        <Template Context="percent">
            @for (var i = 1; i <= 4; i++)
            {
                <span data-filled="@(percent >= i * 25)"
                      class="h-1.5 rounded-full bg-zinc-200 transition-colors group-data-[level=low]:data-filled:bg-red-600 group-data-[level=optimum]:data-filled:bg-amber-600 group-data-[level=high]:data-filled:bg-green-600"></span>
            }
        </Template>
    </BhMeter>
    <span class="text-xs text-zinc-500" id="tw-pw-strength">Strength: <strong class="font-semibold text-zinc-900">@(StrengthLabels[Score()])</strong></span>
</div>

@code {
    private string password = "";
    private static readonly string[] StrengthLabels = ["Very weak", "Weak", "Fair", "Good", "Strong"];

    private int Score()
    {
        if (password.Length == 0) return 0;
        var score = 0;
        if (password.Length >= 8) score++;
        if (password.Any(char.IsUpper) && password.Any(char.IsLower)) score++;
        if (password.Any(char.IsDigit)) score++;
        if (password.Any(c => !char.IsLetterOrDigit(c))) score++;
        return score;
    }
}
