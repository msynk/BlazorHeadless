Collapsible

An interactive component which expands and collapses a panel.

Basic Collapsible

A BhCollapsibleTrigger toggles a BhCollapsibleContent panel. aria-expanded, aria-controls, and aria-labelledby are wired automatically.

Example

Razor

<BhCollapsible class="collapsible">
    <div class="collapsible-header">
        <span>@peduarte starred 3 repositories</span>
        <BhCollapsibleTrigger class="collapsible-trigger">▾</BhCollapsibleTrigger>
    </div>
    <div class="collapsible-row">@radix-ui/primitives</div>
    <BhCollapsibleContent class="collapsible-content">
        <div class="collapsible-row">@radix-ui/colors</div>
        <div class="collapsible-row">@radix-ui/themes</div>
    </BhCollapsibleContent>
</BhCollapsible>

CSS

/* All styles are consumer-authored — the library ships zero CSS */
.collapsible {
    width: 100%;
    border: 1px solid #e4e4e7;
    border-radius: 0.5rem;
    overflow: hidden;
    background: #fff;
}

.collapsible-header {
    display: flex;
    align-items: center;
    justify-content: space-between;
    padding: 0.875rem 1.125rem;
    font-weight: 500;
}

.collapsible-trigger {
    all: unset;
    display: inline-flex;
    align-items: center;
    justify-content: center;
    width: 1.75rem;
    height: 1.75rem;
    border-radius: 0.375rem;
    cursor: pointer;
    color: #71717a;
}

.collapsible-trigger:hover         { background: #f4f4f5; }
.collapsible-trigger:focus-visible { outline: 2px solid #2563eb; outline-offset: 2px; }
.collapsible-trigger[data-disabled]{ opacity: 0.5; cursor: not-allowed; pointer-events: none; }

.collapsible-row {
    padding: 0.75rem 1.125rem;
    color: #71717a;
    border-top: 1px solid #e4e4e7;
}

Default Open

Set DefaultOpen="true" to render the panel open initially (uncontrolled).

Example

Razor

<BhCollapsible DefaultOpen="true" class="collapsible">
    <div class="collapsible-header">
        <span>Already open</span>
        <BhCollapsibleTrigger class="collapsible-trigger">▾</BhCollapsibleTrigger>
    </div>
    <BhCollapsibleContent class="collapsible-content">
        <div class="collapsible-row">I'm open by default. Click the trigger to close me.</div>
    </BhCollapsibleContent>

Render Context (rotating chevron + Close)

BhCollapsibleTrigger and BhCollapsibleContent expose a BhCollapsibleRenderContext via Context="c". Use it to drive UI from the open state and to call c.Close() from anywhere inside.

Example

Razor

<BhCollapsible class="collapsible">
    <div class="collapsible-header">
        <span>What's inside?</span>
        <BhCollapsibleTrigger class="collapsible-trigger" Context="c">
            <span class="collapsible-chevron @(c.IsOpen ? "open" : "")">▾</span>
        </BhCollapsibleTrigger>
    </div>
    <BhCollapsibleContent class="collapsible-content" Context="c">
        <div class="collapsible-row">
            <p>You can close me from inside the content:</p>
            <button class="btn" @onclick="c.Close">Close panel</button>
        </div>
    </BhCollapsibleContent>
</BhCollapsible>

CSS

/* All styles are consumer-authored — the library ships zero CSS */
.collapsible {
    width: 100%;
    border: 1px solid #e4e4e7;
    border-radius: 0.5rem;
    overflow: hidden;
    background: #fff;
}

.collapsible-header {
    display: flex;
    align-items: center;
    justify-content: space-between;
    padding: 0.875rem 1.125rem;
    font-weight: 500;
}

.collapsible-trigger {
    all: unset;
    display: inline-flex;
    align-items: center;
    justify-content: center;
    width: 1.75rem;
    height: 1.75rem;
    border-radius: 0.375rem;
    cursor: pointer;
    color: #71717a;
}

.collapsible-trigger:hover         { background: #f4f4f5; }
.collapsible-trigger:focus-visible { outline: 2px solid #2563eb; outline-offset: 2px; }

.collapsible-row {
    padding: 0.75rem 1.125rem;
    color: #71717a;
    border-top: 1px solid #e4e4e7;
}

/* Rotating chevron driven by BhCollapsibleRenderContext.IsOpen */
.collapsible-chevron      { display: inline-block; transition: transform 200ms ease; }
.collapsible-chevron.open { transform: rotate(180deg); }

/* "Close panel" button rendered inside the content */
.btn {
    display: inline-flex;
    align-items: center;
    gap: 0.4rem;
    margin-top: 0.5rem;
    padding: 0.45rem 0.85rem;
    border: 1px solid #e4e4e7;
    border-radius: 0.5rem;
    background: #fff;
    font-size: 0.875rem;
    font-weight: 500;
    cursor: pointer;
}
.btn:hover { background: #f4f4f5; }

Disabled

Set Disabled="true" on the root to block interaction. The trigger receives both the native disabled attribute and a data-disabled hook.

Example

Razor

<BhCollapsible Disabled="true" class="collapsible">
    <div class="collapsible-header">
        <span>Can't toggle me</span>
        <BhCollapsibleTrigger class="collapsible-trigger">▾</BhCollapsibleTrigger>
    </div>
    <BhCollapsibleContent class="collapsible-content">
        <div class="collapsible-row">You'll never see this content.</div>
    </BhCollapsibleContent>
</BhCollapsible>

Controlled

Drive the open state externally with Open + OnOpenChange. The button below opens or closes the collapsible programmatically.

Example

Razor

<div style="display:flex; flex-direction:column; gap:1rem; width:100%">
    <div class="demo-row">
        <BhButton OnClick="ToggleControlled" class="btn">
            Toggle from outside
        </BhButton>
        <span class="demo-output">Open: @controlledOpen.ToString().ToLowerInvariant()</span>
    </div>

    <BhCollapsible Open="controlledOpen"
                   OnOpenChange="v => controlledOpen = v"
                   class="collapsible">
        <div class="collapsible-header">
            <span>Internal trigger</span>
            <BhCollapsibleTrigger class="collapsible-trigger">▾</BhCollapsibleTrigger>
        </div>
        <BhCollapsibleContent class="collapsible-content">
            <div class="collapsible-row">
                Either trigger updates the same state — fully controlled.
            </div>
        </BhCollapsibleContent>
    </BhCollapsible>
</div>

@code {
    private bool controlledOpen;

    private void ToggleControlled() => controlledOpen = !controlledOpen;
}
