Accordion

A vertically stacked set of collapsible sections, single or multiple open at a time.

Basic Accordion (Single)

Only one item can be open at a time. DefaultValue seeds the initial open item. Each trigger gets aria-expanded and aria-controls automatically.

Example

Razor

<BhAccordion DefaultValue="item-1" class="accordion">
    <BhAccordionItem Value="item-1" class="accordion-item">
        <BhAccordionTrigger class="accordion-trigger" Context="t">
            What is BlazorHeadless?
            <span class="accordion-chevron @(t.IsOpen ? "open" : "")">▾</span>
        </BhAccordionTrigger>
        <BhAccordionContent class="accordion-content">
            <div class="accordion-body">
                BlazorHeadless is a headless component library for Blazor.
                Behaviour and accessibility are built in; styling is entirely up to you.
            </div>
        </BhAccordionContent>
    </BhAccordionItem>

    <BhAccordionItem Value="item-2" class="accordion-item">
        <BhAccordionTrigger class="accordion-trigger" Context="t">
            Why headless?
            <span class="accordion-chevron @(t.IsOpen ? "open" : "")">▾</span>
        </BhAccordionTrigger>
        <BhAccordionContent class="accordion-content">
            <div class="accordion-body">
                You own the look and feel entirely. ARIA and keyboard support never have to be
                re-implemented.
            </div>
        </BhAccordionContent>
    </BhAccordionItem>

    <BhAccordionItem Value="item-3" class="accordion-item">
        <BhAccordionTrigger class="accordion-trigger" Context="t">
            How do I style it?
            <span class="accordion-chevron @(t.IsOpen ? "open" : "")">▾</span>
        </BhAccordionTrigger>
        <BhAccordionContent class="accordion-content">
            <div class="accordion-body">
                Use <code>data-state="open"|"closed"</code> on any element, or just apply
                classes. The library emits no styles of its own.
            </div>
        </BhAccordionContent>
    </BhAccordionItem>
</BhAccordion>

CSS

/* All styles are consumer-authored — the library ships zero CSS */
.accordion {
    width: 100%;
    border: 1px solid #e4e4e7;
    border-radius: 0.5rem;
    overflow: hidden;
}

.accordion-item            { border-bottom: 1px solid #e4e4e7; }
.accordion-item:last-child { border-bottom: none; }

.accordion-trigger {
    all: unset;
    display: flex;
    align-items: center;
    justify-content: space-between;
    width: 100%;
    padding: 1rem 1.25rem;
    font-weight: 500;
    cursor: pointer;
    box-sizing: border-box;
}

.accordion-trigger:hover               { background: #f4f4f5; }
.accordion-trigger:focus-visible       { outline: 2px solid #2563eb; outline-offset: -2px; }
.accordion-trigger[data-state="open"]  { background: #f4f4f5; }
.accordion-trigger[data-disabled]      { opacity: 0.5; cursor: not-allowed; pointer-events: none; }

/* Rotating chevron driven by BhAccordionTriggerContext.IsOpen */
.accordion-chevron      { transition: transform 200ms ease; color: #71717a; }
.accordion-chevron.open { transform: rotate(180deg); }

.accordion-body {
    padding: 0.875rem 1.25rem 1.125rem;
    color: #71717a;
    border-top: 1px solid #e4e4e7;
}

Multiple Open Items

Set Type="BhAccordionType.Multiple" to allow any number of panels open simultaneously.

Example

Razor

<BhAccordion Type="BhAccordionType.Multiple" class="accordion">
    <BhAccordionItem Value="faq-1" class="accordion-item">
        <BhAccordionTrigger class="accordion-trigger" Context="t">
            Can I open multiple panels?
            <span class="accordion-chevron @(t.IsOpen ? "open" : "")">▾</span>
        </BhAccordionTrigger>
        <BhAccordionContent class="accordion-content">
            <div class="accordion-body">
                Yes — every panel is independent. Try opening both!
            </div>
        </BhAccordionContent>
    </BhAccordionItem>

    <BhAccordionItem Value="faq-2" class="accordion-item">
        <BhAccordionTrigger class="accordion-trigger" Context="t">
            Does this one close when I open another?
            <span class="accordion-chevron @(t.IsOpen ? "open" : "")">▾</span>
        </BhAccordionTrigger>
        <BhAccordionContent class="accordion-content">
            <div class="accordion-body">
                No — both can be open at once.
            </div>
        </BhAccordionContent>
    </BhAccordionItem>
</BhAccordion>

CSS

/* Reuses the .accordion / .accordion-trigger styles from the Basic demo.
   With Type="BhAccordionType.Multiple" any combination of items can be open;
   the same data-state="open|closed" hook drives every panel independently. */
.accordion-trigger[data-state="open"]  { background: #f4f4f5; }

Disabled Item

Individual items can be disabled via Disabled="true". The whole accordion can also be disabled at the root.

Example

Razor

<BhAccordion class="accordion">
    <BhAccordionItem Value="d-1" class="accordion-item">
        <BhAccordionTrigger class="accordion-trigger" Context="t">
            I am enabled
            <span class="accordion-chevron @(t.IsOpen ? "open" : "")">▾</span>
        </BhAccordionTrigger>
        <BhAccordionContent class="accordion-content">
            <div class="accordion-body">This item works normally.</div>
        </BhAccordionContent>
    </BhAccordionItem>

    <BhAccordionItem Value="d-2" Disabled="true" class="accordion-item">
        <BhAccordionTrigger class="accordion-trigger" Context="t">
            I am disabled
            <span class="accordion-chevron @(t.IsOpen ? "open" : "")">▾</span>
        </BhAccordionTrigger>
        <BhAccordionContent class="accordion-content">
            <div class="accordion-body">You should not be able to open this.</div>
        </BhAccordionContent>
    </BhAccordionItem>
</BhAccordion>

CSS

/* Hooks emitted when an item is disabled (or the entire accordion is) */
.accordion-trigger[data-disabled] {
    opacity: 0.5;
    cursor: not-allowed;
    pointer-events: none;
}

/* BhAccordionItem itself also receives data-disabled — useful for striping
   the row, dimming icons, etc. */
.accordion-item[data-disabled] {
    background: #fafafa;
}

Controlled Accordion

Drive the open state externally with Value + OnValueChange. The button below toggles "Panel 2" programmatically.

Example

Razor

<div style="display:flex; flex-direction:column; gap:1rem; width:100%">
    <div class="demo-row">
        <BhButton OnClick="ToggleControlledItem" class="btn">
            Toggle "Panel 2"
        </BhButton>
        <span class="demo-output">Open: @(controlledValue ?? "none")</span>
    </div>

    <BhAccordion Value="@controlledValue"
                OnValueChange="v => controlledValue = v"
                class="accordion">
        <BhAccordionItem Value="ctrl-1" class="accordion-item">
            <BhAccordionTrigger class="accordion-trigger" Context="t">
                Panel 1
                <span class="accordion-chevron @(t.IsOpen ? "open" : "")">▾</span>
            </BhAccordionTrigger>
            <BhAccordionContent class="accordion-content">
                <div class="accordion-body">Controlled by external state.</div>
            </BhAccordionContent>
        </BhAccordionItem>

        <BhAccordionItem Value="ctrl-2" class="accordion-item">
            <BhAccordionTrigger class="accordion-trigger" Context="t">
                Panel 2
                <span class="accordion-chevron @(t.IsOpen ? "open" : "")">▾</span>
            </BhAccordionTrigger>
            <BhAccordionContent class="accordion-content">
                <div class="accordion-body">This panel is toggled by the button above.</div>
            </BhAccordionContent>
        </BhAccordionItem>
    </BhAccordion>
</div>

@code {
    private string? controlledValue;

    private void ToggleControlledItem()
    {
        controlledValue = controlledValue == "ctrl-2" ? null : "ctrl-2";
    }
}

CSS

   reflects whatever Value/Values you bind to. */
