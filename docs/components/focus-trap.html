FocusTrap

A low-level component that traps keyboard focus within a container. Used internally by Dialog but also useful standalone for custom modal-like patterns.

Basic Focus Trap

Toggle the trap on and off. While active, pressing Tab and Shift+Tab cycles through the focusable elements inside the container without escaping to the rest of the page. Focus is automatically moved to the first focusable element when the trap activates, and restored to the previously-focused element when it deactivates.

Example

Razor

<BhButton OnClick="() => enabled = !enabled"
          class="btn @(enabled ? "btn-primary" : "")">
    @(enabled ? "Deactivate trap" : "Activate trap")
</BhButton>

<BhFocusTrap Enabled="enabled" class="focus-trap-container">
    <p>Focus is @(enabled ? "trapped" : "free") inside this box.</p>
    <input type="text" placeholder="First input" />
    <input type="text" placeholder="Second input" />
    <button class="btn" @onclick="() => enabled = false">Close</button>
</BhFocusTrap>

@code {
    private bool enabled;
}

CSS

/* All styles are consumer-authored — the library ships zero CSS */
.focus-trap-container {
    display: flex;
    flex-direction: column;
    gap: 0.75rem;
    padding: 1.25rem;
    border: 2px dashed #d4d4d8;
    border-radius: 0.5rem;
    margin-top: 1rem;
}

/* Active state via data-state attribute emitted by BhFocusTrap */
.focus-trap-container[data-state="active"] {
    border-color: #2563eb;
    background: #eff6ff;
}

.focus-trap-label {
    margin: 0;
    font-size: 0.9rem;
    color: #52525b;
}

.focus-trap-input {
    padding: 0.45rem 0.6rem;
    border: 1px solid #d4d4d8;
    border-radius: 0.4rem;
    font-size: 0.9rem;
}

/* Toggle button */
.btn {
    display: inline-flex;
    align-items: center;
    gap: 0.4rem;
    padding: 0.45rem 0.85rem;
    border: 1px solid #e4e4e7;
    border-radius: 0.5rem;
    background: #fff;
    font-size: 0.875rem;
    font-weight: 500;
    cursor: pointer;
}
.btn:hover { background: #f4f4f5; }

.btn-primary {
    color: #fff;
    background: #2563eb;
    border-color: #2563eb;
}
.btn-primary:hover { background: #1d4ed8; border-color: #1d4ed8; }

@code {
    private bool basicEnabled;
}

Slide-over panel

A common use case: a slide-over panel that traps focus while visible. The trap activates when the panel opens and deactivates when it closes, returning focus to the trigger button.

Example

Razor

<BhButton OnClick="() => panelOpen = true" class="btn btn-primary">
    Open panel
</BhButton>

@if (panelOpen)
{
    <div class="slide-over-backdrop" @onclick="() => panelOpen = false"></div>
    <BhFocusTrap Enabled="panelOpen" class="slide-over-panel">
        <h3>Settings</h3>
        <p>Focus is trapped inside this panel.</p>

        <label>
            <span>Username</span>
            <input type="text" value="alice" />
        </label>

        <label>
            <span>Email</span>
            <input type="email" value="alice@example.com" />
        </label>

        <div class="slide-over-actions">
            <button @onclick="() => panelOpen = false">Cancel</button>
            <button @onclick="() => panelOpen = false">Save</button>
        </div>
    </BhFocusTrap>
}

@code {
    private bool panelOpen;
}

Multiple focusable regions

Demonstrates that only the active trap captures focus. Toggle between two regions — only the enabled one traps Tab navigation.

Example

Razor

<BhButton OnClick="ActivateRegionA" class="btn">Trap Region A</BhButton>
<BhButton OnClick="ActivateRegionB" class="btn">Trap Region B</BhButton>
<BhButton OnClick="DeactivateAll" class="btn">Release all</BhButton>

<BhFocusTrap Enabled="regionA" class="focus-trap-container">
    <strong>Region A</strong>
    <input type="text" placeholder="A — Field 1" />
    <input type="text" placeholder="A — Field 2" />
    <button class="btn">A — Action</button>
</BhFocusTrap>

<BhFocusTrap Enabled="regionB" class="focus-trap-container">
    <strong>Region B</strong>
    <input type="text" placeholder="B — Field 1" />
    <input type="text" placeholder="B — Field 2" />
    <button class="btn">B — Action</button>
</BhFocusTrap>

@code {
    private bool regionA;
    private bool regionB;

    private void ActivateRegionA() { regionA = true; regionB = false; }
    private void ActivateRegionB() { regionA = false; regionB = true; }
    private void DeactivateAll() { regionA = false; regionB = false; }
}

CSS

/* All styles are consumer-authored — the library ships zero CSS */
.focus-trap-container {
    display: flex;
    flex-direction: column;
    gap: 0.75rem;
    padding: 1.25rem;
    border: 2px dashed #d4d4d8;
    border-radius: 0.5rem;
    margin-top: 1rem;
}

/* Each region uses the same .focus-trap-container styles. The active one gets
   highlighted via the data-state="active" attribute emitted by BhFocusTrap. */
.focus-trap-container[data-state="active"] {
    border-color: #2563eb;

.focus-trap-input {

    font-size: 0.9rem;

.multi-controls {

    gap: 0.5rem;
}

.multi-regions {
    display: grid;
    grid-template-columns: 1fr 1fr;
    gap: 1rem;
    margin-top: 1rem;
}

/* Toggle buttons */
.btn {
    display: inline-flex;
    align-items: center;
    gap: 0.4rem;
    padding: 0.45rem 0.85rem;
    border: 1px solid #e4e4e7;
