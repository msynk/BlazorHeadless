Dialog

An accessible modal with focus trap, scroll lock, and inert background.

Basic Dialog

Click the button to open the dialog. While open, focus is trapped inside the panel, body scroll is locked, the rest of the page is marked inert, and Escape or clicking the backdrop closes it. Focus is returned to the opener button on close.

Example

Razor

<BhButton OnClick="() => isOpen = true" class="btn btn-primary">
    Open dialog
</BhButton>

<BhDialog Open="isOpen" OnClose="() => isOpen = false">
    <BhDialogBackdrop class="dialog-backdrop" />
    <BhDialogPanel class="dialog-panel">
        <BhDialogTitle class="dialog-title">Welcome aboard</BhDialogTitle>
        <BhDialogDescription class="dialog-description">
            This is a fully-accessible dialog. Try Tab and Shift+Tab — focus
            cycles inside this panel. Press Escape to close.
        </BhDialogDescription>

        <div class="dialog-actions">
            <BhButton OnClick="() => isOpen = false" class="btn">Cancel</BhButton>
            <BhButton OnClick="() => isOpen = false" class="btn btn-primary">Got it</BhButton>
        </div>
    </BhDialogPanel>
</BhDialog>

@code {
    private bool isOpen;
}

CSS

/* The library applies minimal default positioning (position:fixed inset:0)
   so consumers can layer the backdrop and panel inside it. Everything else is yours. */

.dialog-backdrop {
    background: rgba(0, 0, 0, 0.5);
}

.dialog-panel {
    /* Centre the panel in the viewport */
    margin: 4rem auto;
    max-width: 28rem;
    background: #fff;
    border-radius: 0.75rem;
    box-shadow: 0 25px 50px -12px rgba(0, 0, 0, 0.25);
    padding: 1.5rem;
    display: flex;
    flex-direction: column;
    gap: 0.85rem;
}

.dialog-title       { font-size: 1.1rem; font-weight: 600; color: #18181b; }
.dialog-description { font-size: 0.9rem; color: #71717a; }

.dialog-actions {
    display: flex;
    justify-content: flex-end;
    gap: 0.5rem;
    margin-top: 0.5rem;
}

Confirmation (no backdrop dismiss)

Set DismissOnClick="false" on the backdrop and DismissOnEscape="false" on the panel to require an explicit choice. Useful for destructive actions.

Example

Razor

<BhButton OnClick="() => isOpen = true" class="btn">
    Delete account
</BhButton>

<span class="demo-output">@confirmResult</span>

<BhDialog Open="isOpen" OnClose="() => isOpen = false">
    <BhDialogBackdrop class="dialog-backdrop" DismissOnClick="false" />
    <BhDialogPanel class="dialog-panel" DismissOnEscape="false">
        <BhDialogTitle class="dialog-title">Delete account?</BhDialogTitle>
        <BhDialogDescription class="dialog-description">
            This will permanently remove your account and all its data.
            This cannot be undone.
        </BhDialogDescription>

        <div class="dialog-actions">
            <BhButton OnClick="HandleCancel" class="btn">Cancel</BhButton>
            <BhButton OnClick="HandleDelete" class="btn btn-danger">Yes, delete</BhButton>
        </div>
    </BhDialogPanel>
</BhDialog>

@code {
    private bool isOpen;
    private string? confirmResult;

    private void HandleCancel()
    {
        isOpen = false;
        confirmResult = "Cancelled.";
    }

    private void HandleDelete()
    {
        isOpen = false;
        confirmResult = "Account deleted (just kidding).";
    }
}

   so consumers can layer the backdrop and panel inside it. Everything else is yours. */

With form fields

The dialog also works as a focusable form container. Tab cycles between the inputs and buttons; the focus trap keeps them all reachable while keeping the background untouchable.

Example

Razor

<BhButton OnClick="() => isOpen = true" class="btn btn-primary">
    Edit profile
</BhButton>

<span class="demo-output">@formResult</span>

<BhDialog Open="isOpen" OnClose="() => isOpen = false">
    <BhDialogBackdrop class="dialog-backdrop" />
    <BhDialogPanel class="dialog-panel">
        <BhDialogTitle class="dialog-title">Edit profile</BhDialogTitle>
        <BhDialogDescription class="dialog-description">
            Update your display name. Press Escape or click outside to cancel.
        </BhDialogDescription>

        <label class="dialog-field">
            <span>Display name</span>
            <input type="text" @bind="displayName" class="dialog-input" />
        </label>

        <div class="dialog-actions">
            <BhButton OnClick="() => isOpen = false" class="btn">Cancel</BhButton>
            <BhButton OnClick="HandleSave" class="btn btn-primary">Save</BhButton>
        </div>
    </BhDialogPanel>
</BhDialog>

@code {
    private bool isOpen;
    private string? formResult;
    private string displayName = "Alice";

    private void HandleSave()
    {
        isOpen = false;
        formResult = $"Saved: {displayName}";
    }
}

CSS

/* The library applies minimal default positioning (position:fixed inset:0)
   so consumers can layer the backdrop and panel inside it. Everything else is yours. */

.dialog-backdrop {
    background: rgba(0, 0, 0, 0.5);
}

.dialog-panel {

    gap: 0.5rem;
    margin-top: 0.5rem;
}

.dialog-field {
    display: flex;
    flex-direction: column;
    gap: 0.35rem;
    font-size: 0.85rem;
