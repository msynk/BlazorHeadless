Tooltip

A small popup that surfaces information about a control on hover or focus.

Basic Tooltip

Hover or focus the trigger to open the tooltip. Pointer leave, blur, or pressing Escape closes it. aria-describedby wires the content to the trigger automatically.

Example

Razor

<BhTooltipProvider DelayDuration="200">
    <BhTooltip class="tooltip">
        <BhTooltipTrigger class="tooltip-trigger">+ Add to library</BhTooltipTrigger>
        <BhTooltipContent Anchor="@(new BhAnchorOptions { To = "top", Gap = 6 })"
                          class="tooltip-content">
            Adds the item to your library
            <BhTooltipArrow class="tooltip-arrow" />
        </BhTooltipContent>
    </BhTooltip>
</BhTooltipProvider>

Provider configuration

Use BhTooltipProvider to set DelayDuration and SkipDelayDuration globally. Hover one trigger then move quickly to the next — the second tooltip opens instantly because the recently-closed window is still active.

Example

Razor

<BhTooltipProvider DelayDuration="500" SkipDelayDuration="500">
    <div class="tooltip-row">
        <BhTooltip class="tooltip">
            <BhTooltipTrigger class="tooltip-trigger">Save</BhTooltipTrigger>
            <BhTooltipContent Anchor="@(new BhAnchorOptions { To = "top", Gap = 6 })"
                              class="tooltip-content">
                Save changes
                <BhTooltipArrow class="tooltip-arrow" />
            </BhTooltipContent>
        </BhTooltip>
        <BhTooltip class="tooltip">
            <BhTooltipTrigger class="tooltip-trigger">Edit</BhTooltipTrigger>
            <BhTooltipContent Anchor="@(new BhAnchorOptions { To = "top", Gap = 6 })"
                              class="tooltip-content">
                Edit this item
                <BhTooltipArrow class="tooltip-arrow" />
            </BhTooltipContent>
        </BhTooltip>
        <BhTooltip class="tooltip">
            <BhTooltipTrigger class="tooltip-trigger">Delete</BhTooltipTrigger>
            <BhTooltipContent Anchor="@(new BhAnchorOptions { To = "top", Gap = 6 })"
                              class="tooltip-content">
                Permanently delete
                <BhTooltipArrow class="tooltip-arrow" />
            </BhTooltipContent>
        </BhTooltip>
    </div>
</BhTooltipProvider>

CSS

.tooltip-row { display: flex; gap: 0.5rem; align-items: center; }

Show instantly

Set DelayDuration="0" on a tooltip to have it open immediately on hover or focus.

Example

Razor + Tailwind

<BhTooltip DelayDuration="0" class="inline-block">
    <BhTooltipTrigger class="inline-flex items-center gap-2 rounded-lg border border-zinc-300 bg-white px-3.5 py-2 text-sm font-medium cursor-pointer transition-colors hover:border-zinc-400">
        No delay
    </BhTooltipTrigger>
    <BhTooltipContent Anchor="@(new BhAnchorOptions { To = "top", Gap = 6 })"
                      class="z-50 rounded-md bg-zinc-900 px-2.5 py-1 text-xs text-zinc-50 shadow-md">
        I open instantly
    </BhTooltipContent>
</BhTooltip>

Anchor sides and alignment

The Anchor on BhTooltipContent supports top, right, bottom, left with optional start / end alignment. The engine flips and shifts to keep the tooltip in view.

Controlled

Drive the open state externally with Open and OnOpenChange. Useful for guided tours or programmatic highlighting.

Example

Razor + Tailwind

<BhButton OnClick="ToggleControlled"
          class="rounded-lg border border-zinc-200 bg-white px-3 py-1.5 text-sm font-medium hover:bg-zinc-100">
    @(controlledOpen ? "Hide tooltip" : "Show tooltip")
</BhButton>

<BhTooltip Open="controlledOpen" OnOpenChange="v => controlledOpen = v" class="inline-block">
    <BhTooltipTrigger class="inline-flex items-center gap-2 rounded-lg border border-zinc-300 bg-white px-3.5 py-2 text-sm font-medium cursor-pointer">
        Target
    </BhTooltipTrigger>
    <BhTooltipContent Anchor="@(new BhAnchorOptions { To = "top", Gap = 6 })"
                      class="z-50 rounded-md bg-zinc-900 px-2.5 py-1 text-xs text-zinc-50 shadow-md">
        Driven from outside
    </BhTooltipContent>
</BhTooltip>

@code {
    private bool controlledOpen;
    private void ToggleControlled() => controlledOpen = !controlledOpen;
}
