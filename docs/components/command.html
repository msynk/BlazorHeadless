Command Palette

A cmdk-style command menu — fuzzy search, groups, nested pages and a ⌘K palette — with zero visual opinion.

Inline command menu

A search field over a filterable list of actions. The input is a combobox that drives a listbox through aria-activedescendant, so focus never leaves it. Type to fuzzy-filter — "smiley" finds Search emoji through its Keywords — then use ↑ / ↓ (or Ctrl+N / Ctrl+P), Alt+↑ / Alt+↓ to jump between groups, and Enter to run. Empty groups hide, separators disappear while searching, the disabled item is skipped, and the result count is announced.

Nested pages

Turn one menu into a drill-down. Wrap each level in a BhCommandPage (no Name = the root) and navigate with PushPageAsync on the context its Template receives — the search clears on every push. Backspace in an empty input goes back one level, and PageChanged keeps the breadcrumb in sync. Try Settings → Change theme.

@code {
    private readonly List<string> crumbs = new();
    private readonly string[] projects = ["BlazorHeadless", "Docs site", "Samples app", "Design tokens"];
    private readonly string[] themes = ["Light", "Dark", "System"];
    private string theme = "System";
    private string? lastCommand;

    private string PagePlaceholder => crumbs.Count == 0
        ? "What do you need?"
        : $"Search {crumbs[^1].ToLowerInvariant()}…";

    // PageChanged reports the new current page: a pushed page, the page
    // Backspace went back to, or null for the root.
    private void OnPageChanged(string? page)
    {
        var index = page is null ? -1 : crumbs.IndexOf(page);
        if (page is not null && index < 0) crumbs.Add(page);
        else crumbs.RemoveRange(index + 1, crumbs.Count - index - 1);
    }

    // Run the command, then return to the root page.
    private async Task CompleteAsync(BhCommandContext cmd, string command)
    {
        lastCommand = command;
        await cmd.ClearSearchAsync();
        while (cmd.Page is not null)
            await cmd.PopPageAsync();
    }

    private Task SetThemeAsync(BhCommandContext cmd, string option)
    {
        theme = option;
        return CompleteAsync(cmd, $"Theme: {option}");
    }
}

    private void OnPageChanged(string? page)
    {
        var index = page is null ? -1 : crumbs.IndexOf(page);
        if (page is not null && index < 0) crumbs.Add(page);
