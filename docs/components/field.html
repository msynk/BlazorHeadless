Field / Input

Form primitives with auto-wired ARIA labels, descriptions, and validation state.

Basic Field

Wrap a label, input, and description in an BhField. The label's for, the input's id, and the description's aria-describedby are all wired automatically — no manual id management.

Example

Razor

<BhField class="field">
    <BhLabel class="field-label">Email</BhLabel>
    <BhInput type="email" placeholder="you@example.com" class="field-input" />
    <BhDescription class="field-description">We'll never share your email.</BhDescription>
</BhField>

@* Rendered HTML:
   <label for="h-xxxx-input" id="h-xxxx-label">Email</label>
   <input id="h-xxxx-input" type="email" placeholder="you@example.com"
          aria-describedby="h-xxxx-description" />
   <p id="h-xxxx-description">We'll never share your email.</p>
*@

CSS

/* All styles are consumer-authored — the library ships zero CSS */
.field {
    display: flex;
    flex-direction: column;
    gap: 0.35rem;
    width: 100%;
    max-width: 24rem;
}

.field-label {
    font-size: 0.85rem;
    font-weight: 600;
    color: #18181b;
}

.field-label[data-disabled] { opacity: 0.5; }

.field-input {
    padding: 0.5rem 0.75rem;
    border: 1px solid #d4d4d8;
    border-radius: 0.4rem;
    font-size: 0.9rem;
    font-family: inherit;
    color: #18181b;
    background: #fff;
    transition: border-color 120ms ease;
}

.field-input:hover         { border-color: #a1a1af; }
.field-input:focus-visible { outline: 2px solid #2563eb; outline-offset: 1px; }

/* Hooks emitted by BhInput / BhTextarea / BhSelect */
.field-input[data-disabled] { opacity: 0.5; cursor: not-allowed; background: #fafafa; }
.field-input[data-invalid]  { border-color: #dc2626; }
.field-input[data-invalid]:focus-visible { outline-color: #dc2626; }

.field-description {
    font-size: 0.8rem;
    color: #71717a;
    margin: 0;
}

.field-error { color: #dc2626; }

Textarea

BhTextarea works identically to BhInput — same ARIA wiring, same data attributes. Standard HTML attributes like rows pass through.

Example

Razor

<BhField class="field">

    <BhTextarea rows="3" placeholder="Tell us about yourself…" class="field-input" />
    <BhDescription class="field-description">Max 280 characters.</BhDescription>
</BhField>

Disabled Field

Set Disabled="true" on the BhField to disable all children at once. The field, label, and input all receive data-disabled for CSS hooks.

Example

Razor

    <BhInput type="text" value="alice" class="field-input" />
    <BhDescription class="field-description">Cannot be changed.</BhDescription>

    <BhInput type="password" value="123" class="field-input" />
    <BhDescription class="field-description field-error">
        Password must be at least 8 characters.

</BhField>

EditForm validation

Inside an EditForm with DataAnnotationsValidator, every control bound with @@bind-Value / @@bind-Checked reports its validation state to its BhField: the control gets aria-invalid="true" and data-invalid, and BhErrorMessage appears with the messages and is added to the control's aria-describedby — no ids to wire. Non-native controls work too: the radio group is named by its BhLabel via aria-labelledby, and clicking the label focuses the group. Because these components take plain child content, they nest inside EditForm without Context clashes. Submit empty to see it.

Example

Razor

@using System.ComponentModel.DataAnnotations

@* novalidate: let DataAnnotations (not the browser) report errors *@
<EditForm Model="signup" OnValidSubmit="HandleValidSubmit" novalidate="@true" class="field-form validation-form">
    <DataAnnotationsValidator />

    <BhField Required="true" class="field">
        <BhLabel class="field-label">Full name</BhLabel>
        <BhInput @bind-Value="signup.Name" autocomplete="name" class="field-input" />
        <BhErrorMessage class="validation-message" />   @* only rendered while invalid *@
    </BhField>

    <BhField Required="true" class="field">
        <BhLabel class="field-label">Email</BhLabel>
        <BhDescription class="field-description">We'll send the receipt here.</BhDescription>
        <BhInput type="email" @bind-Value="signup.Email" autocomplete="email" class="field-input" />
        <BhErrorMessage class="validation-message" />
    </BhField>

    @* Non-native control: labelled via aria-labelledby, focused by a label click *@
    <BhField Required="true" class="field">
        <BhLabel class="field-label">Plan</BhLabel>
        <BhRadioGroup @bind-Value="signup.Plan" Vertical="false" class="validation-radios">
            <BhRadio Value="Free" class="validation-radio"><span class="validation-radio-dot" aria-hidden="true"></span>Free</BhRadio>
            <BhRadio Value="Pro" class="validation-radio"><span class="validation-radio-dot" aria-hidden="true"></span>Pro</BhRadio>
            <BhRadio Value="Team" class="validation-radio"><span class="validation-radio-dot" aria-hidden="true"></span>Team</BhRadio>
        </BhRadioGroup>
        <BhErrorMessage class="validation-message" />
    </BhField>

    <BhField class="field">
        <div class="validation-check">
            <BhCheckbox @bind-Checked="signup.AcceptTerms" class="checkbox">
                <BhCheckboxIndicator class="checkbox-tick">✓</BhCheckboxIndicator>
            </BhCheckbox>
            <BhLabel class="validation-check-label">I accept the terms of service</BhLabel>
        </div>
        <BhErrorMessage class="validation-message" />
    </BhField>

    <div class="validation-actions">
        <button type="submit" class="btn btn-primary">Create account</button>
        <button type="button" class="btn" @onclick="ResetSignup">Reset</button>
    </div>

    <BhLiveRegion class="validation-success">@signupResult</BhLiveRegion>
</EditForm>

@code {
    private sealed class SignupModel
    {
        [Required(ErrorMessage = "Please enter your name.")]
        public string? Name { get; set; }

        [Required(ErrorMessage = "Please enter your email.")]
        [EmailAddress(ErrorMessage = "That doesn't look like an email address.")]
        public string? Email { get; set; }

        [Required(ErrorMessage = "Pick a plan.")]
        public string? Plan { get; set; }

        [Range(typeof(bool), "true", "true", ErrorMessage = "You must accept the terms.")]
        public bool AcceptTerms { get; set; }
    }

    private SignupModel signup = new();
    private string? signupResult;

    private void HandleValidSubmit() =>
        signupResult = $"Welcome aboard, {signup.Name}! You're on the {signup.Plan} plan.";

    private void ResetSignup()
    {
        signup = new();
        signupResult = null;
    }
}
