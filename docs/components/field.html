Field / Input

Form primitives with auto-wired ARIA labels, descriptions, and validation state.

Basic Field

Wrap a label, input, and description in an BhField. The label's for, the input's id, and the description's aria-describedby are all wired automatically — no manual id management.

Example

Razor

<BhField class="field">
    <BhLabel class="field-label">Email</BhLabel>
    <BhInput type="email" placeholder="you@example.com" class="field-input" />
    <BhDescription class="field-description">We'll never share your email.</BhDescription>
</BhField>

@* Rendered HTML:
   <label for="h-xxxx-input" id="h-xxxx-label">Email</label>
   <input id="h-xxxx-input" type="email" placeholder="you@example.com"
          aria-describedby="h-xxxx-description" />
   <p id="h-xxxx-description">We'll never share your email.</p>
*@

CSS

/* All styles are consumer-authored — the library ships zero CSS */
.field {
    display: flex;
    flex-direction: column;
    gap: 0.35rem;
    width: 100%;
    max-width: 24rem;
}

.field-label {
    font-size: 0.85rem;
    font-weight: 600;
    color: #18181b;
}

.field-label[data-disabled] { opacity: 0.5; }

.field-input {
    padding: 0.5rem 0.75rem;
    border: 1px solid #d4d4d8;
    border-radius: 0.4rem;
    font-size: 0.9rem;
    font-family: inherit;
    color: #18181b;
    background: #fff;
    transition: border-color 120ms ease;
}

.field-input:hover         { border-color: #a1a1af; }
.field-input:focus-visible { outline: 2px solid #2563eb; outline-offset: 1px; }

/* Hooks emitted by BhInput / BhTextarea / BhSelect */
.field-input[data-disabled] { opacity: 0.5; cursor: not-allowed; background: #fafafa; }
.field-input[data-invalid]  { border-color: #dc2626; }
.field-input[data-invalid]:focus-visible { outline-color: #dc2626; }

.field-description {
    font-size: 0.8rem;
    color: #71717a;
    margin: 0;
}

.field-error { color: #dc2626; }

Razor + Tailwind

<BhField class="flex w-full max-w-sm flex-col gap-1.5">
    <BhLabel class="text-sm font-semibold text-zinc-900 data-disabled:opacity-50">Email</BhLabel>
    <BhInput type="email" placeholder="you@example.com"
             class="rounded-md border border-zinc-300 bg-white px-3 py-2 text-sm text-zinc-900 outline-none transition-colors hover:border-zinc-400 focus-visible:outline-2 focus-visible:outline-offset-1 focus-visible:outline-blue-600 data-disabled:bg-zinc-50 data-disabled:opacity-50 data-disabled:cursor-not-allowed aria-invalid:border-red-600 aria-invalid:focus-visible:outline-red-600" />
    <BhDescription class="m-0 text-xs text-zinc-500">We'll never share your email.</BhDescription>
</BhField>

Textarea

BhTextarea works identically to BhInput — same ARIA wiring, same data attributes. Standard HTML attributes like rows pass through.

Example

Razor

<BhField class="field">
    <BhLabel class="field-label">Bio</BhLabel>
    <BhTextarea rows="3" placeholder="Tell us about yourself…" class="field-input" />
    <BhDescription class="field-description">Max 280 characters.</BhDescription>
</BhField>

CSS

/* Reuses the .field / .field-input styles from the Basic demo.
   The textarea just needs a resize rule. */
.field-textarea { resize: vertical; min-height: 4rem; }

Razor + Tailwind

<BhField class="flex w-full max-w-sm flex-col gap-1.5">
    <BhLabel class="text-sm font-semibold text-zinc-900 data-disabled:opacity-50">Bio</BhLabel>
    <BhTextarea rows="3" placeholder="Tell us about yourself…"
                class="rounded-md border border-zinc-300 bg-white px-3 py-2 text-sm text-zinc-900 outline-none transition-colors hover:border-zinc-400 focus-visible:outline-2 focus-visible:outline-offset-1 focus-visible:outline-blue-600 data-disabled:bg-zinc-50 data-disabled:opacity-50 data-disabled:cursor-not-allowed aria-invalid:border-red-600 aria-invalid:focus-visible:outline-red-600 resize-y min-h-16" />
    <BhDescription class="m-0 text-xs text-zinc-500">Max 280 characters.</BhDescription>
</BhField>

Select

BhSelect renders a native <select> with the same auto-wired ARIA. Place <option> elements inside.

Example

Razor

<BhField class="field">
    <BhLabel class="field-label">Country</BhLabel>
    <BhSelect class="field-input field-select">
        <option value="">Choose…</option>
        <option value="us">United States</option>
        <option value="gb">United Kingdom</option>
    </BhSelect>
    <BhDescription class="field-description">Where you're based.</BhDescription>
</BhField>

CSS

/* Reuses the .field / .field-input styles from the Basic demo.
   The select needs a small appearance override. */
.field-select { appearance: none; padding-right: 2rem; }

Razor + Tailwind

<BhField class="flex w-full max-w-sm flex-col gap-1.5">
    <BhLabel class="text-sm font-semibold text-zinc-900 data-disabled:opacity-50">Country</BhLabel>
    <BhSelect class="rounded-md border border-zinc-300 bg-white px-3 py-2 text-sm text-zinc-900 outline-none transition-colors hover:border-zinc-400 focus-visible:outline-2 focus-visible:outline-offset-1 focus-visible:outline-blue-600 data-disabled:bg-zinc-50 data-disabled:opacity-50 data-disabled:cursor-not-allowed appearance-none pr-8">
        <option value="">Choose…</option>
        <option value="us">United States</option>
        <option value="gb">United Kingdom</option>
        <option value="fr">France</option>
        <option value="de">Germany</option>
    </BhSelect>
    <BhDescription class="m-0 text-xs text-zinc-500">Where you're based.</BhDescription>
</BhField>

Disabled Field

Set Disabled="true" on the BhField to disable all children at once. The field, label, and input all receive data-disabled for CSS hooks.

Example

Razor

<BhField Disabled="true" class="field">
    <BhLabel class="field-label">Username</BhLabel>
    <BhInput type="text" value="alice" class="field-input" />
    <BhDescription class="field-description">Cannot be changed.</BhDescription>
</BhField>

@* All children receive data-disabled for CSS hooks. *@

CSS

/* Hooks emitted when Disabled="true" on the field */
.field[data-disabled]       { opacity: 0.6; }
.field-input[data-disabled] { cursor: not-allowed; background: #fafafa; }

Razor + Tailwind

<BhField Disabled="true" class="flex w-full max-w-sm flex-col gap-1.5">
    <BhLabel class="text-sm font-semibold text-zinc-900 data-disabled:opacity-50">Username</BhLabel>
    <BhInput type="text" value="alice"
             class="rounded-md border border-zinc-300 bg-white px-3 py-2 text-sm text-zinc-900 outline-none transition-colors hover:border-zinc-400 focus-visible:outline-2 focus-visible:outline-offset-1 focus-visible:outline-blue-600 data-disabled:bg-zinc-50 data-disabled:opacity-50 data-disabled:cursor-not-allowed" />
    <BhDescription class="m-0 text-xs text-zinc-500">Cannot be changed.</BhDescription>
</BhField>

Invalid Field

Set Invalid="true" on the BhField to mark the input as invalid. The input receives aria-invalid="true" and data-invalid for CSS hooks. Use the description to show an error message.

Example

Razor

<BhField Invalid="true" class="field">
    <BhLabel class="field-label">Password</BhLabel>
    <BhInput type="password" value="123" class="field-input" />
    <BhDescription class="field-description field-error">
        Password must be at least 8 characters.
    </BhDescription>
</BhField>

@* The input receives aria-invalid="true" and data-invalid. *@

CSS

/* Hooks emitted when Invalid="true" on the field */
.field-input[data-invalid] {
    border-color: #dc2626;
}

.field-input[data-invalid]:focus-visible {
    outline-color: #dc2626;
}

.field-error { color: #dc2626; }

Razor + Tailwind

<BhField Invalid="true" class="flex w-full max-w-sm flex-col gap-1.5">
    <BhLabel class="text-sm font-semibold text-zinc-900 data-disabled:opacity-50">Password</BhLabel>
    <BhInput type="password" value="123"
             class="rounded-md border border-zinc-300 bg-white px-3 py-2 text-sm text-zinc-900 outline-none transition-colors hover:border-zinc-400 focus-visible:outline-2 focus-visible:outline-offset-1 focus-visible:outline-blue-600 aria-invalid:border-red-600 aria-invalid:focus-visible:outline-red-600" />
    <BhDescription class="m-0 text-xs text-red-600">
        Password must be at least 8 characters.
    </BhDescription>
</BhField>

Multiple Fields (form layout)

Compose multiple BhField components into a form. Each field manages its own id namespace — no collisions.

Example

Razor

<form class="field-form">
    <BhField class="field">
        <BhLabel class="field-label">First name</BhLabel>
        <BhInput type="text" placeholder="Alice" class="field-input" />
    </BhField>

    <BhField class="field">
        <BhLabel class="field-label">Last name</BhLabel>
        <BhInput type="text" placeholder="Anderson" class="field-input" />
    </BhField>

    <BhField class="field">
        <BhLabel class="field-label">Email</BhLabel>
        <BhInput type="email" placeholder="alice@example.com" class="field-input" />
        <BhDescription class="field-description">Your work email.</BhDescription>
    </BhField>

    <button type="submit" class="btn btn-primary">Submit</button>
</form>

CSS

/* Simple vertical form layout */
.field-form {
    display: flex;
    flex-direction: column;
    gap: 1rem;
    width: 100%;
    max-width: 24rem;
}

Razor + Tailwind

<form class="flex w-full max-w-sm flex-col gap-4" @onsubmit:preventDefault>
    <BhField class="flex w-full flex-col gap-1.5">
        <BhLabel class="text-sm font-semibold text-zinc-900">First name</BhLabel>
        <BhInput type="text" placeholder="Alice"
                 class="rounded-md border border-zinc-300 bg-white px-3 py-2 text-sm text-zinc-900 outline-none focus-visible:outline-2 focus-visible:outline-offset-1 focus-visible:outline-blue-600" />
    </BhField>
    <BhField class="flex w-full flex-col gap-1.5">
        <BhLabel class="text-sm font-semibold text-zinc-900">Last name</BhLabel>
        <BhInput type="text" placeholder="Anderson"
                 class="rounded-md border border-zinc-300 bg-white px-3 py-2 text-sm text-zinc-900 outline-none focus-visible:outline-2 focus-visible:outline-offset-1 focus-visible:outline-blue-600" />
    </BhField>
    <BhField class="flex w-full flex-col gap-1.5">
        <BhLabel class="text-sm font-semibold text-zinc-900">Email</BhLabel>
        <BhInput type="email" placeholder="alice@example.com"
                 class="rounded-md border border-zinc-300 bg-white px-3 py-2 text-sm text-zinc-900 outline-none focus-visible:outline-2 focus-visible:outline-offset-1 focus-visible:outline-blue-600" />
        <BhDescription class="m-0 text-xs text-zinc-500">Your work email.</BhDescription>
    </BhField>
    <BhButton Type="submit"
              class="inline-flex items-center justify-center gap-2 rounded-lg border border-blue-600 bg-blue-600 px-4 py-2 text-sm font-medium text-white cursor-pointer hover:bg-blue-700 self-start">
        Submit
    </BhButton>
</form>
