Hover Card

For sighted users to preview content available behind a link.

Basic

Hover or focus the link to open the card after a short delay. Moving the pointer into the card keeps it open; leaving both the trigger and the card closes it.

Example

Razor

<BhHoverCard class="hover-card">
    <BhHoverCardTrigger class="hover-card-trigger"
                        href="https://github.com/radix-ui" target="_blank" rel="noreferrer">
        @@radix-ui
    </BhHoverCardTrigger>
    <BhHoverCardContent Anchor="@(new BhAnchorOptions { To = "bottom", Gap = 8 })"
                        class="hover-card-content">
        <div class="hc-profile">
            <div class="hc-avatar">R</div>
            <div class="hc-body">
                <div class="hc-name">Radix</div>
                <div class="hc-handle">@@radix-ui</div>
                <p class="hc-bio">Components, icons, colors, and templates...</p>
            </div>
        </div>
        <BhHoverCardArrow class="hover-card-arrow" />
    </BhHoverCardContent>
</BhHoverCard>

CSS

/* All styles are consumer-authored — the library ships zero CSS */
.hover-card { display: inline-block; }

.hover-card-trigger {
    color: #2563eb;
    font-weight: 600;
    text-decoration: none;
    cursor: pointer;
    border-radius: 0.25rem;
}
.hover-card-trigger:hover         { text-decoration: underline; }
.hover-card-trigger:focus-visible { outline: 2px solid #2563eb; outline-offset: 2px; }

.hover-card-content {
    position: relative;
    z-index: 50;
    width: 20rem;
    max-width: calc(100vw - 1rem);
    padding: 1rem;
    background: #fff;
    border: 1px solid #e4e4e7;
    border-radius: 0.6rem;
    box-shadow: 0 10px 30px rgba(0, 0, 0, 0.12);
}
.hover-card-content[hidden] { display: none; }

/* Open / close styling hook */
.hover-card-content[data-state="open"] { animation: hc-fade 150ms ease; }

@keyframes hc-fade {
    from { opacity: 0; transform: translateY(2px); }
    to   { opacity: 1; transform: translateY(0); }
}

/* Arrow — positioned from the resolved data-anchor side */
.hover-card-arrow { fill: #e4e4e7; filter: drop-shadow(0 0 1.5px rgba(0, 0, 0, 0.25)); }
.hover-card-content[data-anchor^="top"]    .hover-card-arrow { position: absolute; bottom: -6px; left: 50%; transform: translateX(-50%); }
.hover-card-content[data-anchor^="bottom"] .hover-card-arrow { position: absolute; top: -6px; left: 50%; transform: translateX(-50%) rotate(180deg); }
.hover-card-content[data-anchor^="left"]   .hover-card-arrow { position: absolute; right: -9px; top: 50%; transform: translateY(-50%) rotate(-90deg); }
.hover-card-content[data-anchor^="right"]  .hover-card-arrow { position: absolute; left: -9px; top: 50%; transform: translateY(-50%) rotate(90deg); }

/* Profile card content */
.hc-profile { display: flex; gap: 0.85rem; }
.hc-avatar {
    flex-shrink: 0;
    width: 3rem; height: 3rem;
    display: flex; align-items: center; justify-content: center;
    border-radius: 100%;
    background: #18181b; color: #fff;
    font-weight: 700;
}
.hc-name   { font-weight: 700; }
.hc-handle { color: #71717a; font-size: 0.85rem; margin-bottom: 0.4rem; }
.hc-bio    { font-size: 0.875rem; line-height: 1.4; margin: 0 0 0.5rem; }
.hc-meta   { display: flex; gap: 1rem; font-size: 0.8rem; color: #52525b; }
.hc-meta strong { color: #18181b; }

.hover-card-row { display: flex; gap: 1.25rem; align-items: center; flex-wrap: wrap; }

Custom delays

Tune OpenDelay and CloseDelay (milliseconds). Here the card opens instantly and lingers for a second after you leave.

Example

Razor

<BhHoverCard OpenDelay="0" CloseDelay="1000" class="hover-card">
    <BhHoverCardTrigger class="hover-card-trigger" href="#">
        Quick open, slow close
    </BhHoverCardTrigger>
    <BhHoverCardContent Anchor="@(new BhAnchorOptions { To = "bottom", Gap = 8 })"
                        class="hover-card-content">
        <p class="hc-bio">Opens with no delay and lingers for a second.</p>
        <BhHoverCardArrow class="hover-card-arrow" />
    </BhHoverCardContent>
</BhHoverCard>

Placement

The Anchor on BhHoverCardContent supports top, right, bottom, left with optional start / end alignment. The engine flips and shifts to keep the card in view.

Example

Razor

<BhHoverCard class="hover-card">
    <BhHoverCardTrigger class="hover-card-trigger" href="#">Top</BhHoverCardTrigger>
    <BhHoverCardContent Anchor="@(new BhAnchorOptions { To = "top", Gap = 8 })" class="hover-card-content">
        <p class="hc-bio">Anchored to the top.</p>
        <BhHoverCardArrow class="hover-card-arrow" />
    </BhHoverCardContent>
</BhHoverCard>

@* ...repeat with To = "right" | "bottom" | "left" *@

Controlled

Drive the open state externally with Open and OnOpenChange. Hovering still works; the button reflects and toggles the same state.

Example

Razor

<BhButton OnClick="() => cardOpen = !cardOpen" class="btn">
    @(cardOpen ? "Hide card" : "Show card")
</BhButton>

<BhHoverCard Open="cardOpen" OnOpenChange="v => cardOpen = v" class="hover-card">
    <BhHoverCardTrigger class="hover-card-trigger" href="#">Target</BhHoverCardTrigger>
    <BhHoverCardContent Anchor="@(new BhAnchorOptions { To = "bottom", Gap = 8 })" class="hover-card-content">
        <p class="hc-bio">Driven from outside via the Open parameter.</p>
        <BhHoverCardArrow class="hover-card-arrow" />
    </BhHoverCardContent>
</BhHoverCard>

@code {
    private bool cardOpen;
}
