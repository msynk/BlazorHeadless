Switch

An accessible on/off toggle with full keyboard support and zero visual opinion.

Basic Switch (Uncontrolled)

Renders a native <button> with role="switch" and aria-checked. Click or press Space/Enter to toggle. DefaultChecked seeds the initial state.

Example

Razor

<BhSwitch DefaultChecked="false" class="switch" Context="s">
    <span class="switch-thumb"
          data-state="@(s.IsChecked ? "checked" : "unchecked")"></span>
</BhSwitch>

CSS

/* All styles are consumer-authored — the library ships zero CSS */
.switch {
    /* Reset native button */
    all: unset;
    box-sizing: border-box;

    /* Track */
    position: relative;
    display: inline-block;
    width: 2.5rem;
    height: 1.4rem;
    border-radius: 999px;
    background: #d4d4d8;
    cursor: pointer;
    transition: background 150ms ease;

    /* Focus ring */
    outline: none;
}

.switch:focus-visible {
    box-shadow: 0 0 0 2px #fff, 0 0 0 4px #2563eb;
}

/* Hooks emitted by BhSwitch */
.switch[data-state="checked"]   { background: #2563eb; }
.switch[data-disabled]          { opacity: 0.5; cursor: not-allowed; }

/* Thumb — driven by data-state on the inner element */
.switch-thumb {
    position: absolute;
    top: 50%;
    left: 0.15rem;
    width: 1.1rem;
    height: 1.1rem;
    background: #fff;
    border-radius: 999px;
    box-shadow: 0 1px 2px rgba(0, 0, 0, 0.2);
    transform: translateY(-50%);
    transition: left 150ms ease;
}

.switch-thumb[data-state="checked"] {
    left: calc(100% - 1.1rem - 0.15rem);
}

Controlled

Drive the state externally with Checked + OnCheckedChange. Clicking either control updates the same state.

Example

Razor

<BhSwitch Checked="@notificationsOn"
         OnCheckedChange="v => notificationsOn = v"
         class="switch" Context="s">
    <span class="switch-thumb"
          data-state="@(s.IsChecked ? "checked" : "unchecked")"></span>
</BhSwitch>

@code {
    private bool notificationsOn = true;
}

Disabled

Set Disabled="true" to block interaction. The button receives the native disabled attribute and a data-disabled hook.

Example

Razor

    <span class="switch-thumb"

With label

As a non-native element

Set As="div" to render as a div. The component automatically adds role="switch", tabindex="0", and Space/Enter keyboard handling so the switch remains fully accessible.

Example

Razor

<BhSwitch As="div" DefaultChecked="false" class="switch" Context="s">
    <span class="switch-thumb"
          data-state="@(s.IsChecked ? "checked" : "unchecked")"></span>
</BhSwitch>

Form Submission

Set Name to render an adjacent <input type="hidden"> so the switch participates in plain form posts. The hidden input is only present when the switch is checked, mirroring native checkbox behaviour.

Example

Razor

<form method="post">
    <label class="switch-label">
        <BhSwitch Name="newsletter" Value="yes"
                 DefaultChecked="false"
                 class="switch" Context="s">
            <span class="switch-thumb"
                  data-state="@(s.IsChecked ? "checked" : "unchecked")"></span>
        </BhSwitch>
        <span>Subscribe to newsletter</span>
    </label>

    <button type="submit">Submit</button>
</form>

@* When checked, posts:  newsletter=yes *@
