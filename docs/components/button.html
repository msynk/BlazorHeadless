Button

A polymorphic, accessible button primitive with loading and disabled states.

Basic Button

Renders a native <button> with no styling. All visuals come from you.

Example

Razor

<BhButton OnClick="HandleBasicClick" class="btn">
    Click me
</BhButton>
<span class="demo-output">Clicked @basicClickCount times</span>

@code {
    private int basicClickCount;

    private void HandleBasicClick() => basicClickCount++;
}

CSS

.btn {
    display: inline-flex;
    align-items: center;
    gap: 0.5rem;
    padding: 0.5rem 1rem;
    font-size: 0.875rem;
    font-weight: 500;
    border: 1px solid #e4e4e7;
    border-radius: 0.5rem;
    background: #fff;
    color: #18181b;
    cursor: pointer;
}

.btn:hover         { background: #f4f4f5; border-color: #d4d4d8; }
.btn:focus-visible { outline: 2px solid #2563eb; outline-offset: 2px; }
.btn:active        { background: #e4e4e7; }

.demo-output {
    font-size: 0.875rem;
    color: #71717a;
}

Razor + Tailwind

<BhButton OnClick="HandleBasicClick"
          class="inline-flex items-center gap-2 rounded-lg border border-zinc-200 bg-white px-4 py-2 text-sm font-medium text-zinc-900 cursor-pointer transition-colors hover:bg-zinc-100 hover:border-zinc-300 active:bg-zinc-200 focus-visible:outline-2 focus-visible:outline-offset-2 focus-visible:outline-blue-600">
    Click me
</BhButton>
<span class="text-sm text-zinc-500">Clicked @basicClickCount times</span>

@code {
    private int basicClickCount;
    private void HandleBasicClick() => basicClickCount++;
}

Disabled State

Sets the native disabled attribute and emits data-disabled for CSS hooks.

Example

Razor

<BhButton Disabled="true" OnClick="HandleBasicClick" class="btn">
    Can't click me
</BhButton>

@code {
    private int basicClickCount;

    private void HandleBasicClick() => basicClickCount++;
}

CSS

.btn {
    display: inline-flex;
    align-items: center;
    gap: 0.5rem;
    padding: 0.5rem 1rem;
    font-size: 0.875rem;
    font-weight: 500;
    border: 1px solid #e4e4e7;
    border-radius: 0.5rem;
    background: #fff;
    color: #18181b;
    cursor: pointer;
}

.btn:hover         { background: #f4f4f5; border-color: #d4d4d8; }
.btn:focus-visible { outline: 2px solid #2563eb; outline-offset: 2px; }
.btn:active        { background: #e4e4e7; }

/* Hooks emitted by BhButton when Disabled="true" */
.btn[data-disabled] {
    opacity: 0.5;
    cursor: not-allowed;
    pointer-events: none;
}

    Can't click me
</BhButton>

Loading State with Context

Uses RenderFragment<BhButtonContext> so you can conditionally render a spinner driven by the button's own state.

Example

Razor

<BhButton Loading="@isLoading" OnClick="HandleLoadingClick" class="btn" Context="btn">
    @if (btn.Loading)
    {
        <span class="spinner"></span>
        <span>Saving…</span>
    }
    else
    {
        <span>Save Changes</span>
    }
</BhButton>

@code {
    private bool isLoading;

    private async Task HandleLoadingClick()
    {
        isLoading = true;
        await Task.Delay(2000);
        isLoading = false;
    }
}

CSS

.btn {
    display: inline-flex;
    align-items: center;
    gap: 0.5rem;
    padding: 0.5rem 1rem;
    font-size: 0.875rem;
    font-weight: 500;
    border: 1px solid #e4e4e7;
    border-radius: 0.5rem;
    background: #fff;
    color: #18181b;
    cursor: pointer;
}

.btn:hover         { background: #f4f4f5; border-color: #d4d4d8; }
.btn:focus-visible { outline: 2px solid #2563eb; outline-offset: 2px; }
.btn:active        { background: #e4e4e7; }

/* Hooks emitted by BhButton when Loading="true" */
.btn[data-loading] {
    opacity: 0.7;
    cursor: wait;
}

.spinner {
    display: inline-block;
    width: 1rem;
    height: 1rem;
    border: 2px solid currentColor;
    border-right-color: transparent;
    border-radius: 50%;
    animation: spin 0.6s linear infinite;
}

@keyframes spin { to { transform: rotate(360deg); } }

Razor + Tailwind

<BhButton Loading="@isLoading" OnClick="HandleLoadingClick"
          class="inline-flex items-center gap-2 rounded-lg border border-zinc-200 bg-white px-4 py-2 text-sm font-medium text-zinc-900 cursor-pointer transition-colors hover:bg-zinc-100 data-loading:opacity-70 data-loading:cursor-wait"
          Context="btn">
    @if (btn.Loading)
    {
        <span class="inline-block h-4 w-4 animate-spin rounded-full border-2 border-current border-r-transparent"></span>
        <span>Saving…</span>
    }
    else
    {
        <span>Save Changes</span>
    }
</BhButton>

@code {
    private bool isLoading;

    private async Task HandleLoadingClick()
    {
        isLoading = true;
        await Task.Delay(2000);
        isLoading = false;
    }
}

Polymorphic Rendering

Set As="a" to render as an anchor while retaining all button semantics. Non-native elements automatically receive role="button", tabindex="0", and Enter/Space keyboard handling.

Example

Razor

<BhButton As="a" href="https://github.com" target="_blank" class="btn btn-link">
    I'm actually an <a> tag
</BhButton>
<BhButton As="span" OnClick="HandleBasicClick" class="btn">
    I'm a <span> with role="button"
</BhButton>

@code {
    private int basicClickCount;

    private void HandleBasicClick() => basicClickCount++;
}

CSS

.btn {
    display: inline-flex;
    align-items: center;
    gap: 0.5rem;
    padding: 0.5rem 1rem;
    font-size: 0.875rem;
    font-weight: 500;
    border: 1px solid #e4e4e7;
    border-radius: 0.5rem;
    background: #fff;
    color: #18181b;
    cursor: pointer;
}

.btn:hover         { background: #f4f4f5; border-color: #d4d4d8; }
.btn:focus-visible { outline: 2px solid #2563eb; outline-offset: 2px; }
.btn:active        { background: #e4e4e7; }

/* Anchor variant of BhButton (As="a") */
.btn-link {
    background: transparent;
    border-color: transparent;
    color: #2563eb;
    text-decoration: underline;
    text-underline-offset: 2px;
}

.btn-link:hover { color: #1d4ed8; background: #eff6ff; }

Razor + Tailwind

<BhButton As="a" href="https://github.com" target="_blank"
          class="inline-flex items-center gap-2 rounded-lg border border-transparent bg-transparent px-4 py-2 text-sm font-medium text-blue-600 underline underline-offset-2 transition-colors hover:bg-blue-50 hover:text-blue-700">
    I'm actually an <a> tag
</BhButton>

<BhButton As="span" OnClick="HandleBasicClick"
          class="inline-flex items-center gap-2 rounded-lg border border-zinc-200 bg-white px-4 py-2 text-sm font-medium text-zinc-900 cursor-pointer transition-colors hover:bg-zinc-100">
    I'm a <span> with role="button"
</BhButton>

@code {
    private int basicClickCount;
    private void HandleBasicClick() => basicClickCount++;
}

Toggle Button

Combine BhButton with your own state to build a toggle. Pass aria-pressed via standard HTML attributes — they merge automatically.

Example

Razor

<BhButton OnClick="TogglePressed"
         class="@ToggleClass"
         aria-pressed="@isPressed.ToString().ToLowerInvariant()">
    @(isPressed ? "ON" : "OFF")
</BhButton>

@code {
    private bool isPressed;

    private string ToggleClass => isPressed ? "btn btn-toggle active" : "btn btn-toggle";

    private void TogglePressed() => isPressed = !isPressed;
}

CSS

.btn {
    display: inline-flex;
    align-items: center;
    gap: 0.5rem;
    padding: 0.5rem 1rem;
    font-size: 0.875rem;
    font-weight: 500;
    border: 1px solid #e4e4e7;
    border-radius: 0.5rem;
    background: #fff;
    color: #18181b;
    cursor: pointer;
}

.btn:hover         { background: #f4f4f5; border-color: #d4d4d8; }
.btn:focus-visible { outline: 2px solid #2563eb; outline-offset: 2px; }
.btn:active        { background: #e4e4e7; }

/* Toggle button — driven by your own aria-pressed state */
.btn-toggle {
    min-width: 4rem;
    justify-content: center;
}

.btn-toggle.active {
    background: #2563eb;
    border-color: #2563eb;
    color: white;
}

Razor + Tailwind

<BhButton OnClick="TogglePressed"
          class="@(isPressed
              ? "inline-flex min-w-16 items-center justify-center gap-2 rounded-lg border border-blue-600 bg-blue-600 px-4 py-2 text-sm font-medium text-white cursor-pointer transition-colors hover:bg-blue-700 focus-visible:outline-2 focus-visible:outline-offset-2 focus-visible:outline-blue-600"
              : "inline-flex min-w-16 items-center justify-center gap-2 rounded-lg border border-zinc-200 bg-white px-4 py-2 text-sm font-medium text-zinc-900 cursor-pointer transition-colors hover:bg-zinc-100 focus-visible:outline-2 focus-visible:outline-offset-2 focus-visible:outline-blue-600")"
          aria-pressed="@isPressed.ToString().ToLowerInvariant()">
    @(isPressed ? "ON" : "OFF")
</BhButton>

@code {
    private bool isPressed;
    private void TogglePressed() => isPressed = !isPressed;
}

Styled via Data Attributes

Style entirely via CSS attribute selectors. No component API for colors, sizes, or variants — that's your domain.

Example

Razor

<BhButton OnClick="HandleBasicClick" class="btn-data">
    Styled via [data-*]
</BhButton>
<BhButton Disabled="true" class="btn-data">
    Disabled via [data-disabled]
</BhButton>
<BhButton Loading="true" class="btn-data">
    Loading via [data-loading]
</BhButton>

@code {
    private int basicClickCount;

    private void HandleBasicClick() => basicClickCount++;
}

CSS

/* Style entirely via CSS attribute selectors emitted by BhButton */
.btn-data                { background: #18181b; color: white; }
.btn-data[data-disabled] { opacity: 0.4; cursor: not-allowed; }
.btn-data[data-loading]  { opacity: 0.7; cursor: wait; }

Razor + Tailwind

<BhButton OnClick="HandleBasicClick"
          class="inline-flex items-center gap-2 rounded-lg border border-transparent bg-zinc-900 px-4 py-2 text-sm font-medium text-white cursor-pointer data-disabled:opacity-40 data-disabled:cursor-not-allowed data-loading:opacity-70 data-loading:cursor-wait">
    Styled via [data-*]
</BhButton>

<BhButton Disabled="true"
          class="inline-flex items-center gap-2 rounded-lg border border-transparent bg-zinc-900 px-4 py-2 text-sm font-medium text-white cursor-pointer data-disabled:opacity-40 data-disabled:cursor-not-allowed data-loading:opacity-70 data-loading:cursor-wait">
    Disabled via [data-disabled]
</BhButton>

<BhButton Loading="true"
          class="inline-flex items-center gap-2 rounded-lg border border-transparent bg-zinc-900 px-4 py-2 text-sm font-medium text-white cursor-pointer data-disabled:opacity-40 data-disabled:cursor-not-allowed data-loading:opacity-70 data-loading:cursor-wait">
    Loading via [data-loading]
</BhButton>

@code {
    private int basicClickCount;
    private void HandleBasicClick() => basicClickCount++;
}
